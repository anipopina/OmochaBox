# かさねて、いろガラス

シアンの丸・黄の角丸四角・マゼンタの三角を滑らせ、重なりの緑・赤・青・暗色を楽しむ遊び。URLは `/kasanete-iroglass/`。

- 重なりを動かさずタップすると、その場所の板を手前から順に選び替え、輪郭で表示します。位置・重なり順・混色は保ちます。次のドラッグで選んだ板を取り出せます。
- 選択せず直接ドラッグすると手前の板を動かします。10 CSS pxを超える移動でドラッグ開始。同じ重なりの24px以内のタップで選択を巡回し、ドラッグの途中・終了時には切り替えません。長押し・ダブルタップは不要です。
- 1本の指で操作。追加の指は無視し、pointer cancel、blur、非表示、リサイズで入力を解除します。位置は保持。画面外へ板全体が出ないように制限。
- 光台へTab移動後、1〜3キーで板を選び、矢印キーでも移動可能。ページ離脱・再入場で初期配置に戻ります。
- 色はCanvasのmultiply合成。物理的に正確な光学シミュレーションではありません。3枚だけを再描画し、常時アニメーションはなし。
- 無音。回転・拡縮・追加・保存・時間制限・物理ライブラリなし。
- 画面案は[素材記録](../../source-assets/kasanete-iroglass/README.md)に保存。配信するのはコード描画のみで巨大画像や指・矢印は表示しません。

`npm run check`、`npm test`。専用検査はビルド後 `node tests/glass.mjs` と `node tests/toy-interactions.mjs`。色の合成、直接タッチ、隠れた板の選択、境界、縦横リサイズ、キャンセル、再入場、キーボードを確認。実機Safari・OSジェスチャーは別途確認が必要です。

フィールドは画面全体に広げ、ヘッダ・個別タイトルは表示しません。戻るボタンは左上に配置し、下部は操作を妨げない案内文だけを重ねます。

Sitesは検証用環境です。入口から通常URLで選択とドラッグを確認できます。比較用クエリや別版はありません。幼児の指のぶれによる誤選択や、輪郭だけで理解できるかは引き続き確認が必要です。AWS本番への公開は別途判断します。
