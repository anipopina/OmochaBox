# かさねて、いろガラス

シアンの丸・黄の角丸四角・マゼンタの三角を滑らせ、重なりの緑・赤・青・暗色を楽しむ遊び。URLは `/kasanete-iroglass/`。

- 板を直接つかんで移動。選択した板は最前面の操作対象になり、輪郭で表示します。
- 1本の指で操作。追加の指は無視し、pointer cancel、blur、非表示、リサイズで入力を解除します。位置は保持。画面外へ板全体が出ないように制限。
- 光台へTab移動後、1〜3キーで板を選び、矢印キーでも移動可能。ページ離脱・再入場で初期配置に戻ります。
- 色はCanvasのmultiply合成。物理的に正確な光学シミュレーションではありません。3枚だけを再描画し、常時アニメーションはなし。
- 無音。回転・拡縮・追加・保存・時間制限・物理ライブラリなし。
- 画面案は[素材記録](../../source-assets/kasanete-iroglass/README.md)に保存。配信するのはコード描画のみで巨大画像や指・矢印は表示しません。

`npm run check`、`npm test`。専用検査はビルド後 `node tests/glass.mjs`。色の合成、直接タッチ、隠れた板の選択、境界、縦横リサイズ、キャンセル、再入場、キーボードを確認。実機Safari・OSジェスチャーは別途確認が必要です。

フィールドは画面全体に広げ、ヘッダ・個別タイトルは表示しません。戻るボタンは左上に配置し、下部は操作を妨げない案内文だけを重ねます。

## 重なりの選択を比較する試作（未採用）

`/kasanete-iroglass/?trial=select` だけで、重なりを動かさずタップすると輪郭の選択が切り替わる比較版を試せます。最初は最前面、同じ重なりを24 CSS px以内で繰り返し触ると前から順に3枚を巡回。タップでは位置・重なり順・混色を変えません。その後ドラッグすると選択した板を取り出せます。選択操作をしていない直接ドラッグは最前面の板を動かします。10 CSS pxを超えた移動でドラッグとなり、終了時には切り替えません。長押しや素早い連続入力は不要。キャンセル・非表示・resizeでは途中入力と次のドラッグ用選択を解除します。通常URLの操作は維持しています。

しきい値と初回選択順は比較用の仮値です。幼児の指の揺れで誤選択しないか、説明なしに下の板を取り出せるかを独立レビューで判断してください。比較検証は `node tests/toy-trials.mjs`。素材・依存・音・画面内ボタンの追加なし。
