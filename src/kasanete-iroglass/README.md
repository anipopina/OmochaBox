# かさねて、いろガラス

シアンの丸・黄の角丸四角・マゼンタの三角を滑らせ、重なりの緑・赤・青・暗色を楽しむ遊び。URLは `/kasanete-iroglass/`。

- 板を直接つかんで移動。形ボタンで選んだ板を最前面の操作対象にするので、完全に隠れた板も取り出せます。選択は輪郭とボタンのチェックで表示。
- 1本の指で操作。追加の指は無視し、pointer cancel、blur、非表示、リサイズで入力を解除します。位置は保持。画面外へ板全体が出ないように制限。
- 形ボタンで選び、光台へTab移動後、矢印キーでも移動可能。リセットは初期の少し重なる配置に戻します。ページ離脱・再入場も初期配置。
- 色はCanvasのmultiply合成。物理的に正確な光学シミュレーションではありません。3枚だけを再描画し、常時アニメーションはなし。
- 無音。回転・拡縮・追加・保存・時間制限・物理ライブラリなし。
- 画面案は[素材記録](../../source-assets/kasanete-iroglass/README.md)に保存。配信するのはコード描画のみで巨大画像や指・矢印は表示しません。

`npm run check`、`npm test`。専用検査はビルド後 `node tests/glass.mjs`。色の合成、直接タッチ、隠れた板の選択、境界、縦横リサイズ、キャンセル、連打、再入場、キーボードを確認。実機Safari・OSジェスチャーは別途確認が必要です。

最終確認（2026-10-25）: 全既存回帰テストと専用テストを通過。親がSites v21でドラッグ、緑・青への色変化、形選択からの取り出し、境界、リセット、入口・再入場を独立操作レビューし、390×844・844×390の実画像を確認済み。自動テストのタッチはChromium DevTools Protocolによる合成入力で、実機タッチではありません。実機Safari・OSジェスチャーは未確認です。

フィールドは画面全体に広げ、ヘッダ・個別タイトルは表示しません。戻るボタンを左上、選択・操作ボタンを下（狭い横画面では右）に重ねます。操作ボタンが覆う部分はボタンの操作を優先します。
