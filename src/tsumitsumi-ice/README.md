# つみつみアイス

3つの味の絵を触り、コーンに好きな順番でアイスを積みます。最大5個で、いっぱいのときは一番上が選んだ味に変わります。コーンを触ると全体が弾み、空のコーンと丸い矢印のボタンで作り直せます。点数・失敗・時間制限はありません。積む色と形を楽しむ静かな遊びとして、音は付けていません。

操作対象は固定し、絵だけを動かします。非表示・離脱・画面サイズ変更時は演出を停止し、積んだ状態を保ちます。再入場では空から始まり、保存はしません。画像の読込中も操作でき、読込失敗時は再読込ボタンを表示します。キーボード、支援技術のクリック、動きを減らす設定に対応します。

入力には共通の間隔を設け、同時入力による意図しない連続追加を抑えます。操作ごとに前の演出を整理し、積む個数と演出数を制限しています。

確認項目：5個の上限と上段の交換、作り直し、連打・複数指、縦横の表示とリサイズ、入口往復・再入場、非表示からの復帰、素材読込失敗。画像素材の出典は [素材メモ](../../source-assets/tsumitsumi-ice/README.md) に記録します。

実装と調整値は [app.ts](app.ts) と、そこから参照するモジュールで管理します。
