# ふきふき、まど

曇った窓を拭くと、明るい庭のねこ・うさぎ・いぬが現れる遊びです。ページURLは `/fukifuki-mado/`。

## 遊び方

| 操作                              | 結果                   |
| --------------------------------- | ---------------------- |
| 窓に触れる・なぞる                | 曇りが消えて庭が見える |
| 雲の「もういちど」                | 窓全体を再び曇らせる   |
| 「もどる」                        | 入口へ戻る             |
| 窓にフォーカスして矢印キー        | 拭きながら位置を移動   |
| 窓にフォーカスしてスペース／Enter | 現在の位置を拭く       |

## 仕様と実装上の注意

- 無音で、点数・達成率・自動終了はありません。
- 最大10指に対応し、非表示・画面離脱・フォーカス喪失時には入力を解除します。
- 画面サイズ変更では拭いた状態を維持し、再入場時には曇った窓に戻ります。
- 動きを減らす設定では、拭いた際の星のアニメーションを止めます。
- 実装は [app.ts](app.ts)、見た目は [style.css](style.css)。庭の画像の上にCanvasを重ね、不透明な消去ブラシで曇りを取り除きます。

## 素材

庭のイラストは、このプロジェクト向けにOpenAIの画像生成で制作したものです。原本・出典・再変換手順は [素材README](../../source-assets/fukifuki-mado/README.md) と [変換記録](../../source-assets/fukifuki-mado/provenance.json) に集約しています。配信用画像は [assets/garden.webp](assets/garden.webp) です。

## 変更時の確認

リポジトリ直下で `npm test` を実行します。タッチとキーボードでの拭き取り、繰り返しの再曇り、複数指・キャンセル、サイズ変更時の状態維持、再入場、動きを減らす設定を確認します。

実機iPhone/iPadでは、複数指・OSジェスチャー・回転・バックグラウンド復帰も確認します。
