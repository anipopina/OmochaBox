# ころんとドミノ

ひとつ触ると、隣へ順番に倒れる木製ドミノの連鎖遊び。崩す・積む操作ではなく、一度の入力が離れた場所まで伝わる様子を楽しみます。空白も最寄りのブロックへ割り当て、狙いを外しても始まります。輪の順路なので、どの位置からも全体へ伝わります。

終了後のタップは配色・並びを替えてもう一度開始。矢印ボタンはいつでも並べ直します。矢印キーで開始位置を選び、Enter/Spaceでも遊べます。連鎖中の入力は予約しません。得点・失敗・時間制限・保存・設定UIなし。

Canvas 2Dによる木の面・厚み・影と、生成木目画像で描画。物理計算ではなく隣接順序を決めたアニメーションなのでWebGL不要です。縦長では個数を減らして大きさを確保。動きを減らす設定では連続回転を省き、順番の姿勢変化で連鎖を示します。静止中に描画ループは動きません。

非表示・blur・離脱では描画と音を停止し、復帰で自動再開しません。次の入力で新しい並びを開始。リサイズ・履歴復帰では配置を初期化します。音は操作で開始する短い低音量の合成音で、外部音源は使いません。

[素材原本・利用条件・変換](../../source-assets/koronto-domino/README.md)。入口画像は企画の素材見本であり、実画面写真ではありません。

`tests/domino-model.mjs` は開始位置・連鎖順序・配置、`tests/domino.mjs` は縦横サイズ、空白・連打・再遊び・キー操作・中断・履歴復帰・入口往復を検査します。実機Safari、音の聴感、幼児による操作確認は別途必要です。
