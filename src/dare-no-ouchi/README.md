# だれのおうち？

大きな扉を触ると、こんこんと揺れて開き、くま・うさぎ・ねこが順番に顔を出します。出ている動物を触ると揺れて応えます。約3.8秒後に扉が閉まり、また遊べます。連打しても登場をやり直したり音を積み重ねたりしません。得点・失敗・時間制限はありません。

- 扉全体が操作領域。タッチ、マウス、Enter、Space、支援技術のクリックに対応。
- 非表示・離脱・リサイズ時はタイマーと音を止め、閉じた状態に戻す。
- 動きを減らす設定では短いフェードと開閉に変更。
- 画像を読み込めない場合は再読み込みボタン。読み込み完了前は開始しない。
- 音は2つの固定正弦波、1音0.18秒、ゲイン各0.007以下、発音間隔300ms以上。音が利用できなくても遊べます。
- `node tests/house.mjs` で専用検証。音の聴感と実機は別途確認が必要。

家は本作業で生成した画像、動物は既存のことこと汽車用生成素材を再利用。詳細は `source-assets/dare-no-ouchi/README.md`。
