# もぐもぐともだち

いちご・バナナ・にんじんをタップすると、おともだちの口へ飛びます。口を閉じて頬を交互に膨らませ、飲み込んでから、食べ物ごとの笑顔と動きを返します。空腹・好き嫌い・得点・悲しい待機はありません。

- 全画面の遊びと共通ホームボタン。食べ物は56px以上のネイティブボタンで、キーボードでも選べます。
- おともだちの広い本体をタップ（Enter・Spaceでも操作）すると、目を細めて短く微笑み、待機中は画像の下中央を基準に身体がやわらかく縮んで戻ります。食事中は目元だけで応じ、食事と次のひとくちは続きます。反応は最新の1回だけで、食べ物はすぐ受け付けます。
- 連打には食べ物の弾みをすぐ返し、次のひとくちは最新の1個だけ保持します。金色の皿とハートが次の選択を示します。
- 非表示・フォーカス喪失・離脱・リサイズでは途中の食事と次の選択を破棄し、笑顔に戻ります。待機中はRAFを停止します。
- 身体画像・食べ物画像と顔のSVGを分離。口に入った食べ物は口形状でクリップし、頬・目・口を別々に制御します。顔の基準座標は500×500です。
- 動きを減らす設定では飛行の弧や身体の跳躍を省き、口と表情による反応を残します。音声や設定UIはありません。

素材の出典と変換記録は [source-assets](../../source-assets/mogumogu-tomodachi/README.md)。

`node tests/mogumogu.mjs` で状態の上限、各食べ物、連打、途中中断、リサイズ、入口と再入場、タッチ・キーボードと素材読み込みを検査します。Chromiumのタッチエミュレーションは実機iPhone/iPadや幼児の操作確認とは別です。
