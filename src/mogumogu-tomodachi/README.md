# もぐもぐともだち

怪獣・おばけ・くまと遊びます。いちご・バナナ・にんじんをタップすると、おともだちの口へ飛びます。口の線と頬を動かしてもぐもぐし、飲み込んでから、食べ物ごとの笑顔と動きを返します。空腹・好き嫌い・得点・悲しい待機はありません。

- 全画面の遊びと共通ホームボタン。食べ物は56px以上のネイティブボタンで、キーボードでも選べます。
- おともだちの広い本体をタップ（Enter・Spaceでも操作）すると、目を細めて短く微笑み、待機中は身体がやわらかく縮む・ぴょこっと跳ねる・左右に揺れる3種類の反応を順番に返します。食事中は目元だけで応じ、食事は続きます。反応は最新の1回だけです。
- 食事中に別の食べ物をタップすると弾む反応だけを返します。予約や自動給餌はありません。
- 選んだ食べ物はその瞬間に台から離れて口へ飛び、飲み込み終わると消費を確定します。3種類を食べ終えると、満足したあと次のおともだちが現れ、食べ物も順に台へ戻ります。最初の友達はランダムで、以後は かいじゅう→くま→おばけ→かいじゅう の固定順です。
- 非表示・フォーカス喪失・離脱・リサイズでは途中の食事を中断し、笑顔に戻ります。飲み込み前の食べ物は台に戻し、飲み込み済みの食べ物は戻しません。最後のひとくちの満足・交代中の中断では次の友達と補充を確定します。待機中はRAFを停止します。
- 3体の本体を先読みしてデコードし、準備済みの画像要素・顔・ラベルを同時に表示します。初回・交代の準備中は顔だけを表示せず、食べ物は消費しません。短い待ち時間に表示がちらつかないよう、砂時計は読み込みが長引いた場合に出します。画像が失敗した場合は読み込めた友達を使い、すべて失敗した場合は指の絵が示すボタンで再試行できます。
- 身体画像・食べ物画像と顔のSVGを分離。口に入った食べ物は口形状でクリップし、頬・目・口を別々に制御します。
- 動きを減らす設定では飛行の弧や身体の跳躍を省き、交代と補充は透明度で表現します。食事中は口と表情の切り替えで伝えます。
- もぐもぐを始めたときと飲み込むときに効果音が鳴ります。おともだちの交代は無音です。候補は開発時の `/mogumogu-tomodachi/?sound-review` で試聴できます。

素材の出典と変換記録は [画像](../../source-assets/mogumogu-tomodachi/README.md) と [効果音](../../source-assets/mogumogu-tomodachi/audio/README.md) を参照してください。

`node tests/mogumogu.mjs` で状態の上限、各食べ物、連打、途中中断、リサイズ、入口と再入場、タッチ・キーボードと素材読み込みを検査します。Chromiumのタッチエミュレーションは実機iPhone/iPadや幼児の操作確認とは別です。

実装と調整値は [app.ts](app.ts) と、そこから参照するモジュールで管理します。
