# ぷくぷくシャボン

空いたところを触ってシャボン玉を作り、泡にもう一度触れるとへこんでぽこんと消えます。点数や制限時間はありません。キーボードではTabで作成面・泡・ホームを選び、Enter/Spaceで操作できます。

泡は直径96/128/160 CSS px、最大18個。単音の合成音は140ms間隔、振幅0.035以下に制限します。非表示・画面離脱・フォーカス喪失時に泡と音を停止し、再タップで再開できます。縮小動作設定では漂いを止めます。

背景は画面端の静かな雲4つ。破裂時だけ6粒の光が270ms広がって消えます（最大108粒、泡と一緒に390ms以内で削除）。縮小動作設定では3粒を移動させず160msで消します。追加タイマー・常時点滅・追加音はありません。

現在は操作レビュー用候補です。[提供された画面イメージ](https://drive.google.com/file/d/1kw7mlzbMSPIPCp6nSxXuWJ8KlpaWgiZi/view)を取得・閲覧し、青空・虹色の縁・白い反射を参考にしました。画像自体は配信しません。泡はCSS、入口図案はインラインSVG、音はWeb Audioによるプロジェクト内制作で、追加の画像・音声ダウンロードや第三者素材はありません。既存ホームアイコンの出典は [共通素材](../shared/icons/README.md) を参照してください。

確認: 入口との往復、泡の作成/変形/消失、連打・複数指、画面回転、非表示からの復帰、実機Safariと音の聴感。自動検証は `node tests/bubbles.mjs`。
