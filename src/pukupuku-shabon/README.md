# ぷくぷくシャボン

空いたところを触ってシャボン玉を作り、泡にもう一度触れるとへこんでぽこんと消えます。点数や制限時間はありません。キーボードではTabで作成面・泡・ホームを選び、Enter/Spaceで操作できます。

ときどき泡に「図形のなかま」が入ります。泡を割ると落ちてきて、ドラッグで動かせます。なかま同士と画面端の衝突にはMatter.jsを使います。たまってきたら古いなかまから小さくなって消えます。端末の傾きが取得できるときは傾けた方向へ動きます。右上に「かたむき」が表示されると、ブラウザーにセンサーの許可を求められます。拒否したあともボタンから再試行できます。ブラウザーに拒否が保存されている場合は、そのブラウザーで許可を変更する必要があります。傾きを取得できない場合は下に落ちます。

泡の数と音量・発音頻度を制限します。非表示・画面離脱・フォーカス喪失時は泡を消さず、位置・サイズ・色と破裂途中の状態を保持して動きと音を一時停止します。表示とフォーカスの復帰後は続きから漂います。音は次の操作時だけ鳴り、復帰だけでは鳴りません。ページ再読み込みは初期状態になります。動きを減らす設定では漂いを止めます。

背景は画面端の静かな雲。破裂時だけ光粒が広がって消えます。動きを減らす設定では光粒を移動させず短く表示します。常時点滅は使いません。調整値は [app.ts](app.ts) と [style.css](style.css) を参照してください。

[提供された画面イメージ](https://drive.google.com/file/d/1kw7mlzbMSPIPCp6nSxXuWJ8KlpaWgiZi/view)の青空・虹色の縁・白い反射を参考にしました。泡はCSS、入口図案はインラインSVG、音はWeb Audioで制作しています。「図形のなかま」とホームアイコンの出典はそれぞれ [キャラクター素材記録](../../source-assets/characters/README.md) と [共通アイコン](../shared/icons/README.md) を参照してください。

確認: 入口との往復、泡の作成/変形/消失、連打・複数指、画面回転、非表示からの復帰、実機Safariと音の聴感。自動検証は `node tests/bubbles.mjs`。

当たり判定を確認するときは `/pukupuku-shabon/?debug=shapes` で開き、キャラクター入りの泡を割ります。水色の実線が Matter.js の衝突形状、画面端より少し内側の線が壁の位置です。手足など、衝突形状の外にある絵は画面端で見切れることがあります。
