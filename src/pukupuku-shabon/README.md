# ぷくぷくシャボン

空いたところを触ってシャボン玉を作り、泡にもう一度触れるとへこんでぽこんと消えます。点数や制限時間はありません。キーボードではTabで作成面・泡・ホームを選び、Enter/Spaceで操作できます。

泡の数と音量・発音頻度を制限します。非表示・画面離脱・フォーカス喪失時は泡を消さず、位置・サイズ・色と破裂途中の状態を保持して動きと音を一時停止します。表示とフォーカスの復帰後は続きから漂います。音は次の操作時だけ鳴り、復帰だけでは鳴りません。ページ再読み込みは初期状態になります。動きを減らす設定では漂いを止めます。

背景は画面端の静かな雲。破裂時だけ光粒が広がって消えます。動きを減らす設定では光粒を移動させず短く表示します。常時点滅は使いません。調整値は [app.ts](app.ts) と [style.css](style.css) を参照してください。

[提供された画面イメージ](https://drive.google.com/file/d/1kw7mlzbMSPIPCp6nSxXuWJ8KlpaWgiZi/view)を取得・閲覧し、青空・虹色の縁・白い反射を参考にしました。画像自体は配信しません。泡はCSS、入口図案はインラインSVG、音はWeb Audioによるプロジェクト内制作で、追加の画像・音声ダウンロードや第三者素材はありません。既存ホームアイコンの出典は [共通素材](../shared/icons/README.md) を参照してください。

確認: 入口との往復、泡の作成/変形/消失、連打・複数指、画面回転、非表示からの復帰、実機Safariと音の聴感。自動検証は `node tests/bubbles.mjs`。
