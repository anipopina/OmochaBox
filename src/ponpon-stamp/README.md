# ぽんぽんスタンプ

図形6体・水族館10体の絵柄を選び、白い紙面をタップしてスタンプを置く創作遊び。URLは `/ponpon-stamp/`。

- キャラを選ぶ → 紙をタップして離す → 大小・小さな傾きのスタンプが一度弾み、その場に残ります。
- 長押しすると通常のランダムサイズより大きく成長します。光の輪と絵柄のプレビューで大きさを示し、上限では成長・回転を止めます。指を動かしても、離した位置に1個押します。最大10指で別々に操作できます。
- 右上の「あたらしい かみ」で確認なしに白紙へ戻します。
- 配置数には上限を設けます。満杯でも既存の作品は消えません。新しい紙で続けられます。
- キーボードではキャラボタンを選び、紙にフォーカス。矢印で場所を動かし、Space／Enterで1個ずつ押します。キーリピートでは増えません。
- 点数・時間制限・作品保存・外部通信・追加依存はありません。音と短い振動は常時有効です。
- 回転・サイズ変更時は正規化座標から配置を復元し、サイズにかかわらず押した位置を中心に置き、紙面外を切り取ります。サイズ変更・blur・キャンセルでは押しかけの入力を破棄。非表示時は作品を保持し、入力・弾みを停止します。ページ離脱で作品を消し、再入場は白紙です。
- reduced-motionではスタンプは弾まず即座に置き、粒子の数・表示時間・移動を抑えます。長押し中は成長だけを表示し、輪の回転を止めます。長押しの成長中以外はRAFループを停止します。

完成時は、生成された背景ではなく白い紙の上に、既存SVGの鮮やかななかまたちが大小で残ります。選択したキャラには青枠とチェックを表示。縦の小画面は下に3列×2段、狭い横画面は右に2列×3段、広い画面は6列のパレットを置きます。左右の大きな三角ボタンでページを切り替えます。端数ページもパレットの大きさを保ち、紙面のサイズが変わりません。

## 素材

`src/assets/characters/shapes/` の6SVGと `aquarium/` のユーザー提供10SVGを変更せず参照します。[出典・原本一致記録](../../source-assets/characters/README.md) を保持します。顔・手足・輪郭は原本のまま。企画画像は構図参照専用で配信せず、[素材記録](../../source-assets/ponpon-stamp/README.md) に保存します。

## 検証

`npm run check`、`npm test`。単独検査はビルド後 `node tests/stamp.mjs`。セット境界がページ途中にある構成の実ブラウザー検査は `npm run test:stamp-boundaries`。紙面タップ、多指、ドラッグ／cancel、中断、白紙への切替、上限、回転、再入場、キーボード、reduced-motion、各端末寸法と画像の読込を確認します。実機Safari・OSジェスチャーは別途確認が必要です。[ページ送りの検証記録](../../docs/ponpon-pagination-verification.txt) に対象ケースと結果をまとめます。

## ページと選択

- セット名やセット選択ボタンは表示せず、定義順の全スタンプを6個ずつ表示します。左右の◀／▶で双方向に循環します。
- 最初は1ページ目の赤い四角。ページを替えるたび、そのページの先頭を選びます。選択中の絵柄は必ず画面内に青枠とチェックで表示し、見えない選択を持ち越しません。
- ページを替えても紙面は残り、異なるページ・セットの絵柄を混在できます。「あたらしい かみ」は現在のページと選択を保持します。再入場は白紙で、通常の新規読込では1ページ目から始まります。
- 画像decode完了前のタップは配置せず、後で再生もしません。押下中のページ／絵柄切替は未確定入力を破棄します。ページボタンのフォーカスは切替後も維持し、キーボードでも操作できます。
- 絵柄の定義は [sets.ts](sets.ts) に集約します。セットの境界で改ページせず、全項目を通してページ分けします。
- 配置は項目を直接保持し、現在のページや並び順に依存しません。ページ・作品は永続保存しません。

## 配置フィードバック

調整値・上限は [feedback.ts](feedback.ts)、[app.ts](app.ts)、[style.css](style.css) を参照してください。

- 配置時は丸・きらめき・紙吹雪が広がり、大きなスタンプでは粒子も拡大します。粒子数に上限を設け、白紙への切替・リサイズ・非表示・離脱でも後始末します。全面フラッシュや連続点滅は使いません。
- Web Audioの短い合成音を鳴らします。音量・同時発音数・発音頻度を制限し、音声再開が遅れた古い要求は再生しません。非表示・離脱で停止します。
- Vibration APIが使える場合は短い単発の振動を要求します。APIなし・拒否・例外でも遊びを継続します。戻り値は実際の振動を保証しません。
- 音／振動の変更UIや設定保存はありません。
- 振動は [API仕様](https://www.w3.org/TR/vibration/#vibration-interface) に従って利用可否を判定し、権限変更や非標準の回避処理は行いません。対応端末を前提にしません。
- CDP合成入力、ネイティブWeb Audioの生成・上限・suspend、振動APIのテスト代替で要求値を検査します。実機の音色・音量・触覚・Safariは未検証です。

フィールドは画面全体に広げ、ヘッダ・個別タイトルは表示しません。戻るボタンは左上、新しい紙のボタンは右上に配置します。選択ボタンは下（狭い横画面では右）に直接重ね、パネルの背景や隙間は紙面への操作を妨げません。
