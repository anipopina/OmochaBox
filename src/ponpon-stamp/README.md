# ぽんぽん、スタンプ

6体のなかまを選び、白い紙面をタップしてスタンプを置く静かな創作遊び。URLは `/ponpon-stamp/`。

- キャラを選ぶ → 紙をタップして離す → 大小・小さな傾きのスタンプが一度弾み、その場に残ります。
- なぞる操作は描画せずキャンセル。最大10指で別々のタップに対応します。
- 「もどす」で最後の1個を消します。「あたらしい かみ」は絵付き確認画面で決定したときだけ消します。戻る矢印またはEscapeで取り消せます。
- 最大60個。満杯でも既存の作品は消えません。もどす／新しい紙で続けられます。
- キーボードではキャラボタンを選び、紙にフォーカス。矢印で場所を動かし、Space／Enterで1個ずつ押します。キーリピートでは増えません。
- 無音、点数・時間制限・保存・外部通信・追加依存はありません。
- 回転・サイズ変更時は正規化座標から配置を復元し、端のキャラを紙面内に収めます。サイズ変更・blur・キャンセルでは押しかけの入力を破棄。非表示時は作品を保持し、入力・弾み・確認画面を停止します。ページ離脱で作品を消し、再入場は白紙です。
- reduced-motionでは弾まず即座に置きます。常時アニメーション／RAFループはありません。

完成時は、生成された背景ではなく白い紙の上に、既存SVGの鮮やかななかまたちが大小で残ります。選択したキャラには青枠とチェックを表示。縦の小画面は下に3×2パレット、横の小画面は右に操作欄を置きます。

## 素材

`src/assets/characters/` のユーザー提供6SVGを変更せず参照します。顔・手足・輪郭は原本のまま。企画画像は構図参照専用で配信せず、[素材記録](../../source-assets/ponpon-stamp/README.md) に保存します。

## 検証

`npm run check`、`npm test`。単独検査はビルド後 `node tests/stamp.mjs`。紙面タップ、多指、ドラッグ／cancel、中断、undo、確認画面、上限、回転、再入場、キーボード、reduced-motion、各端末寸法と画像の読込を確認します。実機Safari・OSジェスチャーは別途確認が必要です。
