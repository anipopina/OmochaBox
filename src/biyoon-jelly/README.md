# びよーんゼリー

大きなゼリーを指でつまんで上下左右に伸ばし、離すとぷるんと戻る、弾力を楽しむ遊びです。タップだけでもつぶれて戻ります。得点、失敗、時間制限、設定UIはありません。音は使わず、指に追従する形と戻る動きで反応を伝えます。

- ゼリーの下端は皿の上に固定し、縦横の伸縮と左右の傾きで変形します。変形には上限を設け、画面外へ引っ張っても形が際限なく大きくなりません。
- 1本目の指だけを追跡します。途中の別の指は無視し、キャンセル・フォーカス離脱・画面非表示・リサイズでは入力と動きを解除します。操作していない間の描画ループはありません。
- キーボードでは矢印キーで伸ばし、離すと戻ります。Enter／Spaceは押してつぶし、離して戻します。読み上げソフトのクリックでも弾みます。
- 動きを減らす設定では指への追従は保ち、離した後の往復を省いて短く元の形へ戻します。
- 再入場は初期状態。保存や外部通信はありません。画像読込みに失敗したときは再読込みボタンを出します。

既存の風船の「膨らませて空に見送る」、いろガラスの「板を移動し色を重ねる」と異なり、指を動かしている間の連続した変形を主役にしています。

素材の出典・最適化は [素材記録](../../source-assets/biyoon-jelly/README.md) を参照してください。

固有検証は `node tests/jelly.mjs`。複数画面サイズ、ドラッグ中と離した後、画面外へ伸ばす操作、キャンセル、複数指、キーボード、非表示・再入場、減らした動き、画像復旧を対象とします。実機のタッチ感と幼児による評価は別途必要です。
