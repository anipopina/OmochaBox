# むにゅっとねんど

大きなねんどを押すとくぼみ、その周囲が盛り上がります。なぞると太い溝がつながり、指を離してもその形が残ります。ねんど玉と矢印の大きなボタンで丸め直せます。ゼリーの復元弾力や、土を消して隠れたものを探す遊びとは異なる、形を残す触感遊びです。

- 固定192×192の高さの面へ押し込みを記録。中心から下げた量を周囲へ配り、上下限を設けます。完全な体積保存や物理シミュレーションではありません。操作履歴・DOM・タイマーは積み増しません。
- 入力は1本目の指のみ。高速移動を補間し、1フレームの処理量に上限を設けます。キャンセル・非表示・blur・リサイズでは入力と動きを停止し、完成した形を保持。再入場は初期状態。保存・外部通信・音・得点・時間制限・設定UIなし。
- 矢印キーで押す位置を選び、Enter/Spaceで押します。動きを減らす設定では追従補間を省いて形を即時更新。
- 操作後だけ高さへ追従して描画し、静止後は描画ループを停止。丸め直し画像に失敗しても矢印操作で遊べます。
- [生成素材原本・仕様・出典・変換記録](../../source-assets/munyutto-nendo/README.md)。見本画像は材質参考で、配信には丸いねんど玉だけを利用します。

専用検証は `node --import tsx tests/clay-model.mjs` と `node tests/clay.mjs`。へこみ・盛上り・連続溝・入力上限・大量入力・サイズ別操作・中断・再入場を検査します。実機Safari・幼児操作は別途必要です。AWS本番公開対象には追加しません。
