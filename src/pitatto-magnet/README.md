# ぴたっとマグネット

磁石を動かして、近くの玩具を引き寄せる遊び。玩具をタップするだけでも磁石が近づきます。付いた玩具は揺れながら追随し、磁石をタップすると離れて散ります。吸着していない磁石をタップすると、弾みながら近くの玩具を集めます。ドラッグ後に指を離すだけでは玩具は離れません。

- 玩具は6個。距離で吸引を開始し、一度付いた玩具は解放まで追随します。解放後は移動・タップまで吸引を止めます。
- 1本目の指だけを追跡。小さな指のぶれはタップとして扱います。矢印キーで磁石を移動、Enter/Spaceや支援技術のクリックで集める・解放できます。
- 音、得点、失敗、時間制限、設定UI、ストレージ、外部通信はありません。
- 非表示・離脱・リサイズでは入力とアニメーションを停止。再入場は初期状態。停止中の描画ループはありません。
- 画像失敗時は再読込みボタン。動きを減らす設定では振り子と反動を省きます。

素材は [出典記録](../../source-assets/pitatto-magnet/README.md) を参照してください。専用検証は `node --import tsx tests/magnet-model.mjs` と `node tests/magnet.mjs`。制作時の検証結果と未確認事項は [完成記録](../../docs/reviews/2026-11-05-pitatto-magnet.md) にまとめています。

実装と調整値は [app.ts](app.ts) と、そこから参照するモジュールで管理します。
