# くるっとえほん

ページ中央のタップでも次へ進みます。ページをめくって3つの景色を行き来する、文字のない絵本遊び。右下の大きな矢印をタップすると次、左下で前へ。ページ右半分から左へ引くと次、左半分から右へ引くと前のページを途中までめくれます。途中で離すと、十分引いた場合は完了し、短い移動なら元に戻ります。最後から最初へ循環します。

- 1本目の指のみ追跡。操作中の追加入力でめくり直しません。
- キーボードの左右矢印、ボタンのEnter/Space、pointerイベントを伴わないクリックに対応。pointerup後のclickはめくり中のbusy状態で二重実行を防ぎます。
- 非表示、blur、離脱、画面サイズ変更で途中の操作・タイマーを止め、現在ページに戻します。再入場では最初のページ。
- 動きを減らす設定では紙の折り返しを短いクロスフェードに変更。音・点滅・得点・失敗・時間制限・設定UI・ストレージ・外部通信はありません。
- 画像を事前読込みし、失敗時は再読込みボタンを表示。

素材の出典は [素材記録](../../source-assets/kurutto-ehon/README.md) を参照してください。固有の検証対象は `node tests/ehon.mjs`。制作時の検証結果は [完成確認記録](../../docs/reviews/2026-11-06-kurutto-ehon.md) にまとめています。
