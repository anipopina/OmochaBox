# ころころ、すべりだい

顔のない大きな供給球をタップすると、その色のたまが赤→黄→青の曲線斜面を交互にころがり、受け皿で弾む遊び。URLは `/korokoro-suberidai/`。

- 赤・黄・青の3ボタン。タッチ、マウス、キーボード（Space / Enter）、読み上げソフトのボタン操作に対応。長押しキーのリピートでは増やしません。
- 無音。点数、失敗、時間制限、保存、外部通信、追加依存はありません。
- たまは最大24個・8.5秒。満杯なら最も古い1個と交代し、連打を受け付けます。たまが消えるとRAFを停止します。
- SVGの共通座標で斜面と経路を表現。斜面端のカーブと落下、受け皿の減衰する3回の弾みを接続します。衝突計算は行いません。
- サイズ変更時は進行状況を保持して全体を同じ比率で縮尺変更。横の小画面では供給球を左側に配置します。
- 非表示・ページ離脱でたまを片付け、再入場は空のすべりだいから始めます。
- 動きを減らす設定では経路移動と弾みをせず受け皿に静止表示。3.5秒で消えます。設定変更時は現在のたまを片付けます。
- 企画PNGは参照のみで配信しません。斜面、たま、受け皿は軽量なSVG/CSSのグラデーションで立体感を表現します。[素材記録](../../source-assets/korokoro-suberidai/README.md)。

## 検証

`npm run check` と `npm test`。単独はビルド後 `node tests/slide.mjs`。
タッチ、3色、連打上限、キーボード、サイズ変更、入口往復・再入場、非表示・離脱、軽減動作、経路接続、寿命後の停止を検査し、縦横各画面の画像を保存します。実機Safari・OSジェスチャーは別途確認が必要です。
