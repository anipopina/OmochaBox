# ことこと汽車

大きな汽車を触ると、軽く弾んで短い汽笛とともに短く走ります。背景が流れ、自然に減速して止まります。走行中の追加タップは反応を返しますが、走行時間は積み増しません。乗客を触ると、その子が前足を上げた姿で左右に揺れてごあいさつします。点数・時間制限・BGM・設定はありません。

非表示・blur・画面回転・ページ離脱では走行と音を停止し、背景の位置は保持。戻ってから次のタップで走れます。動きを減らす設定では背景を動かさず短い明暗の反応にします。音声利用不可でも操作できます。Enter/Spaceに対応。

音源・視覚効果を再利用し、連打でも積み増しません。走行のRAFは停止時に終了。素材・原本・生成記録は `source-assets/kotokoto-kisha/`。

`node tests/train.mjs` はモデルの時間上限、6画面サイズ、タッチ、乗客の反応、連打、音源上限、非表示・回転・再入場・キーボード・reduced-motion・音声失敗を検査します。実機・幼児操作・音の聴感は未確認です。

乗客の絵は客車前面の後ろで左右に揺れます。透明な操作ボタンは固定し、画像下端は縁より下に配置して隠します。

実装と調整値は [app.ts](app.ts) と、そこから参照するモジュールで管理します。
