# みずたまり

浅いアクアの水面を触ると大きな同心円が広がり、近い浮き葉を少しずつ運べる遊び。URLは `/mizutamari/`。

- タップで即座に波紋。ドラッグは時間と距離の間隔を設けて次の波紋を作ります。最大10指で同時に触れます。
- 波紋の数と表示時間に上限を設けます。上限では最古の波紋と交代。3枚の葉は近い入力で少しずつ移動し、その場に落ち着きます。反対側を触ると進む向きが変わります。葉の速度を制限し、葉が画面外へ消えない余白を確保します。静止後はRAFを止めます。
- キーボードは水面にTabフォーカス、矢印で位置を動かしてEnter／Space。キーリピートでは波紋を増やしません。
- キャンセル／lostpointercaptureでは該当指を解除。blur・非表示・ページ離脱・resizeでは入力と演出を片付けます。blur・非表示では移動済みの葉の位置を保持。resizeと再入場は静かな初期配置。
- reduced-motionでは葉を動かさず、短い静止輪郭で反応します。設定変更時は途中の演出を停止します。
- Canvas 2Dの解像度と描画面積に上限を設けます。固定3枚の葉と有限の波紋のみ。追加依存なし。
- 無音・振動なし。個別設定、点数、時間制限、保存、外部通信はありません。

自然物はOpenAIの画像生成で本企画向けに生成された葉2種の透過WebP。3枚に大きさ・角度の変化をつけます。企画参照の指・枠・文字は表示しません。[素材の出典](../../source-assets/mizutamari/README.md)。

`npm run check`、`npm test`。専用はビルド後 `node tests/pond.mjs` と `node tests/toy-interactions.mjs`。モデル上限／収束、6画面サイズ、タップ・複数指・ドラッグ・キャンセル、キーボード、resize、非表示相当の後始末、軽減動作、入口往復と再入場を確認。CDP合成タッチとヘッドレスChromiumの画像検査であり、実機Safari・OSジェスチャーの確認ではありません。

実装と調整値は [app.ts](app.ts) と、そこから参照するモジュールで管理します。
