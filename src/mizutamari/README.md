# みずたまり

浅いアクアの水面を触ると大きな同心円が広がり、近い浮き葉がふわっと揺れる遊び。URLは `/mizutamari/`。

- タップで即座に波紋。ドラッグは90ms以上・36 CSS px以上離れた場所に次の波紋を作ります。最大10指で同時に触れます。
- 波紋は最大32個・2.2秒。上限では最古の波紋と交代。3枚の葉は近い入力で小さく動き、減衰して元の場所へ戻ります。静止後はRAFを止めます。
- キーボードは水面にTabフォーカス、矢印で位置を動かしてEnter／Space。キーリピートでは波紋を増やしません。
- キャンセル／lostpointercaptureでは該当指を解除。blur・非表示・ページ離脱・resizeでは入力と演出を片付けます。再入場は静かな初期配置。
- reduced-motionでは葉を動かさず、短い静止輪郭を500msで消します。設定変更時は途中の演出を停止します。
- Canvas 2D、DPR上限2・描画面積約300万px上限。固定3枚の葉と有限の波紋のみ。追加依存なし。
- 無音・振動なし。個別設定、点数、時間制限、保存、外部通信はありません。

自然物はOpenAI image_genで本企画向けに生成された葉2種の透過WebP（256×256、合計32,914 bytes）。3枚に大きさ・角度の変化をつけます。企画参照の指・枠・文字は表示しません。[素材の出典](../../source-assets/mizutamari/README.md)。

`npm run check`、`npm test`。専用はビルド後 `node tests/pond.mjs`。モデル上限／収束、6画面サイズ、タップ・複数指・ドラッグ・キャンセル、キーボード、resize、非表示相当の後始末、軽減動作、入口往復と再入場を確認。CDP合成タッチとヘッドレスChromiumの画像検査であり、実機Safari・OSジェスチャーの確認ではありません。

## 葉を運ぶ比較試作（未採用）

`/mizutamari/?trial=carry` だけで、近くの波紋が葉を少しずつ押し、その場に落ち着く比較版を試せます。反対側を触ると逆方向へ進みます。通常URLの元へ戻る揺れは維持しています。最大速度60 CSS px/秒、葉の大きさに応じた画面内の余白、3枚・波紋32個の上限を維持。静止後はRAF停止。blur／非表示では波紋と速度を止め、移動済みの位置は保持。resizeと再入場では初期配置へ戻ります。reduced-motionは葉の移動なし。追加素材・依存・音なし。AWS公開対象は変更していません。

比較検証は `node tests/toy-trials.mjs`。採用・本番公開は別途判断します。
