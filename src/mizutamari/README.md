# みずたまり

浅いアクアの水面を触ると大きな同心円が広がり、近い浮き葉を少しずつ運べる遊び。URLは `/mizutamari/`。

- タップで即座に波紋。ドラッグは時間と距離の間隔を設けて次の波紋を作ります。最大10指で同時に触れます。
- 波紋は真上から見た同心円です。帯の中で砂利をずらして屈折に見せ、淡い光と影が水面になじむように境界をぼかします。屈折を描く波紋数には上限があり、古い波紋は光と影で見せます。
- 葉は近い入力で少しずつ移動し、その場に落ち着きます。反対側を触ると進む向きが変わります。葉の速度を制限し、葉が画面外へ消えない余白を確保します。静止後はRAFを止めます。
- キーボードは水面にTabフォーカス、矢印で位置を動かしてEnter／Space。キーリピートでは波紋を増やしません。
- キャンセル／lostpointercaptureでは該当指を解除。blur・非表示・ページ離脱・resizeでは入力と演出を片付けます。blur・非表示では移動済みの葉の位置を保持。resizeと再入場は静かな初期配置。
- reduced-motionでは葉の移動と屈折を省き、短く留まる淡い光と影で反応します。設定変更時は途中の演出を停止します。
- Canvas 2Dの解像度と描画面積に上限を設けます。葉の枚数はフィールドの面積、サイズは短辺に応じて決めます。
- 水面に触れたときとキーボードで波紋を作ったときに、短い「ぽちょっ」が少しずつ違う速さで鳴ります。ドラッグで続けて出る波紋には音を重ねません。
- 振動、個別設定、点数、時間制限、保存、外部通信はありません。

砂利と浮き葉は、OpenAIの画像生成で制作したWebPです。砂利の上にCSSで水の色を重ね、縦長画面には中心部を切り出した軽い画像を使います。浮き葉は緑の楕円葉、青緑の丸葉、ヤナギ、ツタの4種類です。[素材の出典](../../source-assets/mizutamari/README.md)。

開発サーバーの `/mizutamari/?sound-review` で候補を聴き比べられます。「選んだ音で遊ぶ」で水面の操作と合わせて確認できます。[効果音素材の記録](../../source-assets/mizutamari/audio/README.md)

`pnpm run check`、`pnpm test`。専用はビルド後 `node tests/pond.mjs` と `node tests/toy-interactions.mjs`。モデル上限／収束、6画面サイズ、タップ・複数指・ドラッグ・キャンセル、キーボード、resize、非表示相当の後始末、軽減動作、入口往復と再入場を確認。CDP合成タッチとヘッドレスChromiumの画像検査であり、実機Safari・OSジェスチャーの確認ではありません。

実装と調整値は [app.ts](app.ts) と、そこから参照するモジュールで管理します。
