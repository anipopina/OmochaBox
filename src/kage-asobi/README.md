# のびのび、かげあそび

大きな太陽形のライトを動かし、うさぎの影の向き・長さが連続して変わる関係を試す遊び。光を左へ動かすと影は右へ、うさぎへ近づけると長く伸びます。描いた軌跡を残すおえかきとは異なり、同じ物の影を何度でも変えることが核です。得点・失敗・時間制限はありません。

下側の領域でライトを動かせます。空いた場所のタップもライト位置へ割り当て、上側を触った場合は移動領域の近い端へ寄せます。矢印キーでも前後左右へ移動でき、Enter/Spaceと支援技術のクリックは左右の配置を切り替えます。戻すボタンで初期位置へ。別の指は操作を奪いません。

影は同じ透過画像のシルエットを足元から投影します。実際の光線追跡ではなく、幼児が結果を見分けやすいよう画面内で長さを制限する2D表現です。画像は [素材原本と変換記録](../../source-assets/kage-asobi/README.md) を参照。共通の戻るボタン・favicon・OGPを使用します。

描画ループ・音声コンテキスト・タイマーは持たず、入力時とリサイズ時に更新します。非表示・blur・離脱・pointercancelでドラッグと短い装飾アニメーションを解除し、復帰で古い入力を再開しません。動きを減らす設定でも影は直接入力に追従し、装飾だけを省きます。リサイズ時は相対的な光の位置を維持します。ページ再入場は初期状態です。

効果音は未採用・候補未制作です。無音を最終採用したという意味ではありません。将来の音選定は [効果音の制作・選定](../../docs/sound-review.md) に従います。

`npm run test:toy -- kage-asobi` で、投影モデル、5画面サイズのタッチ操作・複数指・キャンセル・キー操作・中断復帰・入口の保存済み表示設定を確認します。独立した実画面レビュー、実機Safariと幼児による操作確認は別途必要です。
