# くるくる、かざぐるま

赤・黄・緑・青の折り紙風の風車に、指で風を送る遊び。URLは `/kurukuru-kazaguruma/`。

- 大きな風車をタップすると回転。払う方向・距離で回転方向と速さを変えられます。中心近くでは左右の動きでも回せます。
- 逆方向へ払うとその方向へ切り替わります。最高速度は毎秒180度、時間に応じて自然に減速し、停止後はRAFを停止します。
- キーボードはSpace／Enterで回転、左右キーで方向指定。キーリピートでは加速しません。読み上げソフトのボタン操作にも対応します。
- 操作中は1本の指を捕捉し、追加の指は無視します。キャンセル・フォーカス喪失・画面サイズ変更・非表示で入力と回転を停止。角度は保持し、復帰時は次の操作を待ちます。
- ページ離脱では角度もリセットし、再入場は静止状態から始めます。
- 動きを減らす設定では慣性回転を行わず、1回のタップ・スワイプ・キー操作で12度ずつ向きを変えます。途中の設定変更では回転を止めます。
- 無音。点数・制限時間・保存・外部通信・追加依存はありません。

羽根は曲線の輪郭、明暗のある折れ面、折り目を備えた4色SVG。木の棒と丸い留め具を組み合わせ、入口カードも同じ羽根を参照します。[企画画像・素材記録](../../source-assets/kurukuru-kazaguruma/README.md)。

## 検証

`npm run check` と `npm test`。ビルド後の単独検証は `node tests/pinwheel.mjs`。
