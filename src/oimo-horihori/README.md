# おいもほりほり

真上から見た畑をなでたりタップし、土からサツマイモを探します。ほぼ全体が見えたら、芋への別タップで持ち上がり、弾んで右下のカゴへ入ります。文字の掛け声・点数・制限時間・引っ張り操作はありません。

- 通常と細長い芋を交互に配置。毎回位置・角度を変えます。画面外や戻るボタン・カゴの背後を避け、葉とは少し重なります。極小の画面のみ収容を優先します。
- 中央の円と不均一な周辺の小円を同じ形で描画・判定し、格子状のセルで露出を管理。同一点の反復や長押しで周囲を自動的に掘る補助はありません。
- 芋の不透明部分がほぼ露出したら小さな残土を除き、収穫待ちを光と弾みで示します。外周の土を掃除する必要はなく、最後の掘削入力では収穫しません。
- カゴには不揃いな角度・大きさの芋が重なり、収穫に応じて増えて見えます。表示数を制限し、その後も豊作の見た目を保ちます。カゴを触ると揺れます。
- Enter/Spaceでも操作可能。無音。回転で掘削状態を保持し、pointercancel・非表示・離脱時に入力を解除。再入場は初期状態からです。
- 原本・出典・変換記録は [source-assets](../../source-assets/oimo-horihori/README.md)。

`tests/oimo-model.mjs` と `tests/oimo.mjs` で掘削形、反復、露出閾値、別入力収穫、UI回避、9サイズ、回転、カゴ、キャンセル、非表示、入口往復を検査します。実機Safari・幼児による確認は別途必要です。

実装と調整値は [app.ts](app.ts) と、そこから参照するモジュールで管理します。
