# おいもほりほり

土を大きくなでたりタップしてどけ、サツマイモがほぼ全部見えたら、もう一度触って「すぽん！」と持ち上げる遊びです。長い引っ張り・連打ゲージ・点数・制限時間はありません。

- 掘った場所を保持し、表示中のお芋の不透明画素を基準に、各お芋の93%以上をどけるまで収穫しません。外周の空いた土まで掃除する必要はありません。最後のひとなででは収穫せず、次の入力を待ちます。
- 通常・細長いおいも・つながった2本の株を順番に繰り返します。収穫後に自動で次の土へ。かごには直近4株が並び、触ると弾みます。
- 広い指判定。既に掘った場所で指を動かさずタップすると近い土8区画ずつを補助的にどけます。ドラッグでは補助せず実際の経路を掘ります。Enter/Spaceでも操作可能。無音で、画像・形・粒子・動きで反応を伝えます。
- 画面回転で掘った状態を保持します。pointercancel・非表示・離脱で入力を解除し、収穫中なら次の土へ進めます。再入場では初期状態に戻ります。
- 素材の原本と変換記録は [source-assets](../../source-assets/oimo-horihori/README.md)。公開コードに私的な名前・写真などは含めません。

独立テストは `tests/oimo-model.mjs` と `tests/oimo.mjs`。露出の閾値、同一点の反復、別入力での収穫、連続入力、反復、各サイズ、回転、キャンセル、非表示、入口往復を確認します。実機Safari・第三者による実操作確認は別途必要です。
