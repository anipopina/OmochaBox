# ぷかぷか、ふうせん

大きな黄色いポンプを押すと、顔のある風船がふくらみ、離すと空へ飛びます。URLは `/pukapuka-fusen/`。

## 遊び方

- ポンプを押す：最大までふくらみ、そのまま安定します。
- 離す：風船がゆっくり上へ、少し横へ漂います。短いタップでも飛びます。
- スペース／Enter：押して成長、離して放出。読み上げソフトのボタン操作にも対応します。
- もどる：入口へ戻ります。

無音。点数・失敗・破裂・自動終了はありません。青い丸、星、三角、紫の丸、コーラルの四角、ミントの長方形の順に繰り返します。

## 状態と負荷

一度にポンプを押せる指は1本です。余分な指は無視します。ポインターを捕捉するので、ポンプ外へ指を動かして離しても飛びます。キャンセル・フォーカス喪失・サイズ変更では放出せずに入力を解除します。非表示・ページ離脱時は入力と風船をすべて片付けます。

風船の数に上限を設け、放出または最後に弾いてから一定時間の無操作で終了。寿命後はDOMから削除します。成長完了かつ浮遊風船なしではrequestAnimationFrameを止めます。画像は6種類を再利用します。保存状態・外部通信・音声・追加依存関係はありません。

動きを減らす設定では案内のアニメーション・揺れ・移動を止め、放出した風船を空に静止表示して最後にフェードさせます。横向きの小画面ではポンプを右側に配置します。

## 素材と検証

制作時の画像生成による画面案を参考に、既存マスコットの顔・輪郭を使った派生SVGを使用します。原本6SVGは変更しません。[素材記録](../../source-assets/pukapuka-fusen/README.md)を参照してください。

`npm run check`、`npm test`。専用テストは `node tests/balloon.mjs`（ビルド済みのdistを使用）。短いタップ、上限まで長押し、繰り返し、2本指、cancel、キーリピート、非表示／離脱、画面変更、reduced-motion、6種類の画像読込と順番の一巡、入口往復と画面寸法を検証します。実機Safari・OSジェスチャーは別途確認が必要です。

## 浮遊風船を弾く

風船の左上を触ると右下、左下なら右上、右上なら左下、右下なら左上へ弾きます。強さにはゆらぎがあります。上側を続けて触ると少し下へ押し戻せ、同じ風船と長く遊べます。風船ごとに入力間隔を設け、速度は積み増さず、画面の左右・下端を越えないようにします。無音で、短く白い縁を添えます。Enter／Spaceでは中央寄りの斜め上へ弾けます。reduced-motionでは移動を増やさず、放出から一定時間後に終了します。

実装と調整値は [app.ts](app.ts) と、そこから参照するモジュールで管理します。
