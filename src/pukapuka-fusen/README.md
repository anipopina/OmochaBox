# ぷかぷか、ふうせん

大きな黄色いポンプを押すと、顔のある風船がふくらみ、離すと空へ飛びます。URLは `/pukapuka-fusen/`。

## 遊び方

- ポンプを押す：最大までふくらみ、そのまま安定します。
- 離す：風船がその場からゆっくり浮き始め、上へ少し横に漂います。短いタップでも飛びます。
- 最初から浮いている2つ：最初にポンプを押すと、その場からゆっくり浮き上がります。先に触れると、その風船を弾けます。
- スペース／Enter：押して成長、離して放出。読み上げソフトのボタン操作にも対応します。
- もどる：入口へ戻ります。

点数・失敗・破裂・自動終了はありません。青い丸、星、三角、紫の丸、コーラルの四角、ミントの長方形の順に繰り返します。

## 状態と負荷

一度にポンプを押せる指は1本です。余分な指は無視します。ポインターを捕捉するので、ポンプ外へ指を動かして離しても飛びます。キャンセル・フォーカス喪失・サイズ変更では放出せずに入力を解除します。非表示・ページ離脱時は入力と風船をすべて片付けます。

風船の数に上限を設け、放出または最後に弾いてから一定時間の無操作で終了。寿命後はDOMから削除します。成長完了かつ浮遊風船なしではrequestAnimationFrameを止めます。画像は6種類を再利用します。追加依存関係はありません。

動きを減らす設定では案内のアニメーション・揺れ・移動を止め、放出した風船を空に静止表示して最後にフェードさせます。横向きの小画面ではポンプを右側に配置します。

## 効果音

ポンプを押すと最大サイズまで空気音が続き、途中で離すと短くフェードします。最大サイズでは短い合図が1回鳴ります。風船を放す音は2種類、弾く音は3種類から、その都度ランダムに鳴ります。

開発サーバーの `/pukapuka-fusen/?sound-review` で候補を聴き比べられます。「選んだ音で遊ぶ」では、放す音のC・D、弾く音のC・D・Eをそれぞれランダム再生のグループとして試せます。[効果音の制作・選定](../../docs/sound-review.md)・[素材記録](../../source-assets/pukapuka-fusen/audio/README.md)

## 素材と検証

制作時の画像生成による画面案を参考に、既存マスコットの顔・輪郭を使った派生SVGを使用します。原本6SVGは変更しません。[素材記録](../../source-assets/pukapuka-fusen/README.md)を参照してください。

`pnpm run check`、`pnpm test`。専用テストは `node tests/balloon.mjs`（ビルド済みのdistを使用）。短いタップ、上限まで長押し、繰り返し、2本指、cancel、キーリピート、非表示／離脱、画面変更、reduced-motion、6種類の画像読込と順番の一巡、入口往復と画面寸法を検証します。実機Safari・OSジェスチャーは別途確認が必要です。

## 浮遊風船を弾く

最初から浮いている風船も、飛んでいる風船も、中央から離れたところを触ると反対側へ弾みます。端まで届かなくても最大の強さで押せます。中央に近いほど弾む方向にばらつきが加わります。上の外側を触ると一度下がってから浮き上がります。風船ごとに入力間隔を設け、速度は積み増さず、画面の左右・下端を越えないようにします。Enter／Spaceでも弾けます。「動きを減らす」設定では、その場で輪郭が光ります。

実装と調整値は [app.ts](app.ts) と、そこから参照するモジュールで管理します。
