# ぽろんギター

4本の太い弦を触ると「ぽろん」、横になでると順番に鳴る楽器遊び。通常の入口と `/poron-guitar/` から開きます。ド・ミ・ソ・高いドの和音に合わせた音で、BGM・得点・時間制限・失敗はありません。

- 弦の操作領域は大きなネイティブボタン。縦持ちでは横になで、横持ちでは楽器を回して画面に収めます。TabとEnter／Space、読み上げソフトのボタン操作にも対応。
- 速いなで操作で途中の弦を飛ばさないよう、指の移動経路を補間。最大10指、弦ごとに90msの発音間隔。余分な入力を音の待ち行列にしません。
- Web Audioの固定4音源を再利用。各音源のゲイン最大0.18、共通ゲイン0.12。最大同時入力でも音源を増やさず、短い立ち上がりと約0.9秒の減衰を付けます。音声ファイル・BGM・自動再生・音量設定UIなし。1100msの無操作で音声処理をsuspendします。
- 最初の操作でAudioContextを作成。音声再開が遅れた場合は150msを超えた要求や離した指の要求を破棄。音が使えない場合も見た目の反応は継続。
- 弦の揺れと輪は各弦1組、約600msで終了。常時RAFなし。reduced-motionでは揺れ・拡大を省き、200msの淡い反応のみ。
- 非表示、blur、離脱、画面変更、動作軽減設定変更時は入力・演出・音を停止。再入場で古い入力や音を再生しません。

本企画用に生成したギターの透過WebPを再利用し、弦はコードで独立して動かします。[素材記録](../../source-assets/poron-guitar/README.md)。追加ライブラリ・保存・外部通信なし。AWS本番の公開対象には追加していません。

`npm run check`、`npm test`。専用はビルド後 `node tests/guitar.mjs`。6画面サイズ、素材読込、大きな対象、タップ・速いなで・複数指・キャンセル・キー・再入場、連打の音源／描画上限、非表示・resize・軽減動作・音声失敗時を検査します。ヘッドレスChromiumの合成タッチと音声API検査であり、実機iPhone/iPad・音の聴感・幼児の反応は未確認です。
