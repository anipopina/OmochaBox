# ぽこぽこポップコーン

大きな6粒を触ると、ふわっとポップコーンに変わって跳ねます。できたコーンをもう一度触るとまた跳ねます。粒と丸い矢印の絵ボタンで新しい6粒へ戻せます。得点・制限時間・失敗・調理の待ち時間はありません。

操作領域は動く絵とは別の固定ボタンで、タッチ・マウス・Enter・Space・支援技術のクリックに対応。粒は勝手に消えません。非表示・離脱・リサイズでは音と動きだけを停止して状態を保持し、入口から入り直すと新しい粒になります。動きを減らす設定では短い不透明度の変化に置き換えます。

各粒の絵と光のアニメーションは再利用します。音は固定音源を使い、発音間隔と音量を制限します。無操作時に描画ループはなく、音も停止します。読み込み失敗は再試行可能で、音が使えなくても遊べます。

素材は本プロジェクト用に画像生成しWebP化。原本・変換記録は `source-assets/pokopoko-popcorn/`。専用テストは `node tests/popcorn.mjs`。実機と音の聴感は別途確認が必要です。

実装と調整値は [app.ts](app.ts) と、そこから参照するモジュールで管理します。
