# ぷくぷくシャボン 操作レビュー

## 起動

保存済み OmochaBox Codex Web 環境で:

```sh
cd /workspace/OmochaBox
npm run preview -- --host 0.0.0.0
```

ローカル `http://localhost:4173/` の「ぷくぷくシャボン」カード、または `/pukupuku-shabon/` を開きます。外部公開はしていません。環境のポート転送がない場合は、この環境内ブラウザーかソースを取得したローカルで確認してください。

## 操作レビュー

1. 空いた場所をタップ。指の近くに大きな泡が生まれること。
2. 浮いた泡を触る。横に柔らかくへこんでから輪が消えること。同じ場所への連打も確認。
3. 大小・色の違い、同時に2本以上の指、四隅、戻るボタンの近くを試す。
4. 18個を超えて作る。古い泡が入れ替わり、操作が重くならないこと。
5. 縦横回転、別タブへの移動と復帰、ホーム→再入場。
6. 端末音量を小さくして音を確認。連打・複数指でも突然大きくならないか、音の高さや消え際が心地よいか。
7. iPhone/iPad Safari実機で、画面端のOS操作、音声開始、背景復帰、ホームの押しやすさを確認。

## 自動検証と証跡

- `npm run check`: 型、ESLint、Prettier成功。
- `npm run build`: 全遊びのレビュー用ビルド成功。泡固有JS 3,513 bytes、CSS 3,453 bytes（共通部除外）。
- `npm test` の先行部分: 本番選択/インフラ、出力、素材、ブランド、既存描画・窓のブラウザー回帰成功。
- 新規登録で旧テストの9カード固定値が失敗したため10カードへ修正し、風船以降を再実行し、風船・スタンプ・すべりだい・風車・いろガラス・みずたまり・もぐもぐ・シャボンまで全て成功（終了コード0）。生ログは `test-results/shabon-validation/` に保存。
- 専用検証: 320×568、390×844、568×320、844×390、820×1180、1280×800。CDPのタッチで作成/変形/消失、1000入力でも18個以内、複数指、キーボード、リサイズ、reduced-motion時RAF停止、blur/pagehide/hiddenで停止、再入場、JS例外なし。
- 音: 実Web Audio起動、最大同時1音、gain 0.035上限、連打時発音制限、blurで停止、API利用不可でも操作継続を検証。物理端末での音圧/聴感は未確認。
- スクリーンショット: `test-results/bubbles-*.png`、`test-results/bubbles-pop-*.png`。390px画面を目視確認。

## 復元

変更は専用ブランチの未コミット作業として保存。基点SHAへ適用可能な `test-results/shabon-review-v2.patch` と、`dist/` を固めた `test-results/shabon-review-v2-build.zip` を用意する。パッチの適用先は基点SHAの別チェックアウトを推奨。ビルドZIPは展開したディレクトリをHTTPサーバーで配信する（file://では起動不可）。

## 独立レビュー反映（v2）

- 画面端に静止した柔らかな雲を4つ追加。背景はタッチを受け取らず、中央は空ける。追加画像/依存なし。
- 破裂時に光粒6つを270msだけ放射状に動かす。明滅の反復なし。泡に付属するので同時18個でも108粒上限、連打による重複なし、390ms以内に削除。
- reduced-motionでは3粒を移動させず160msで消す。音の合成処理・音量・同時発音数は初回候補のまま。
- 6画面サイズのタッチ作成/破裂、光粒の可視性と削除、108粒上限、重複防止、非表示時の後始末、reduced-motion、音の上限/不可時フォールバック、入口往復の専用テスト成功。390px縦画面・844px横画面のスクリーンショットを目視確認。
- 実機Safari、音の聴感、低性能端末の継続負荷は引き続き未確認。
