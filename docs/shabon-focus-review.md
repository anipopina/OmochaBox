# シャボン：フォーカス保持・線削除の確認候補

基点 main: `6460b88ba48a169afea039451d56edaa0647b194`。ブランチ `fix/shabon-preserve-focus`。push・公開は行わない。

## 変更

- blur / 非表示 / pagehide は削除でなく一時停止。泡の位置、サイズ、色、漂いの位相、破裂途中の状態を保持する。
- RAFとCSSアニメーションを停止し、発音を止める。復帰時は停止時間を除いて続きから再開する。非表示中のfocusだけでは再開しない。
- 音は復帰だけでは鳴らさず、次の操作で再開する。遅れて解決した音声開始要求も背景で鳴らさない。
- 泡の内側の白い曲線（`.film::after`）のみ削除。白い丸い反射、虹色の縁、雲、光粒、音量は維持。
- 再読み込みや新規入場は初期状態。履歴復元で同じページが保たれる場合はpageshowで再開できる。

## 独立レビュー

保存済み環境の `http://localhost:4173/pukupuku-shabon/` で確認。停止している場合:

```sh
cd /workspace/OmochaBox
npm run preview -- --host 0.0.0.0
```

ポートにアクセスできない場合はレビューZIPを展開し、展開先で `python3 -m http.server 4173` を実行して `http://localhost:4173/pukupuku-shabon/` を開く。公開中のSitesは旧版のままなので今回の確認には使わない。

1. 泡を3つ以上作り、位置・大小・色を覚える。
2. 別ウィンドウをクリックして数秒待つ。見えている泡が消えずに止まること。
3. 元のウィンドウへ戻る。同じ泡がその位置から自然に漂い、復帰だけでは音が鳴らないこと。
4. 別タブへ切り替え、数秒後に戻る。同じ泡が残ること。
5. 泡を割る途中に切り替え、戻ると残りの変形・光粒が終わること。
6. 泡の内側の白い曲線がなく、白い丸い反射や虹色の縁が残っていること。
7. 再タップ時の作成・破裂・音、戻る→再入場、画面回転も確認。

専用テストは6画面サイズ、実Chromiumのタブ切り替え、合成blur/focus・visibility・pagehide/pageshow、位置保持・復帰・音停止/復帰時無音、破裂途中の保持、reduced-motion、1000入力上限、入口往復を含む。実機Safari、OSのアプリ切り替え、音の聴感、実ブラウザーのBFCache履歴復元は未確認。
