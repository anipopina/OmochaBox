## 開き方

確認用ZIPを空のフォルダへ展開し、`python3 -m http.server 8000` を実行して `http://localhost:8000/` を開きます。入口の「ぽろんギター」、または `/poron-guitar/`。Sitesは検証用環境なので別試作モード・クエリは設けていません。今回はpush・Sites公開を保留しています。

## 操作と確認点

1. 赤・黄・緑・紫の太い弦を触る。弦が揺れ、小さな輪が出て、ド・ミ・ソ・高いドが鳴る。長押しを続けても自動で鳴り続けません。
2. 弦を横切るようになでる。縦持ちでは横方向、横持ちでは画面上の弦を縦方向に横切る。速くなでても途中の弦が鳴ること、逆方向にも弾けることを確認。
3. 連打・複数指で音が急に大きくならないこと、無操作で余韻が収まり、音や画面の反応が積み残されないことを確認。
4. Tab・Enter／Spaceで弾く。入口へ戻って再入場、別タブ往復、縦横回転で古い音・入力が残らないことを確認。
5. OSの動きを減らす設定では、弦の揺れと輪の拡大を省いた短い反応になる。音が利用できない環境でも見た目で遊べます。
6. 入口から風船・みずたまり・いろガラス・もぐもぐ・シャボン等も開いて回帰を確認。

実機iPhone/iPad、OS固有ジェスチャー、音色・実音量の聴感、幼児の気づきやすさは未確認です。自動検査は音声APIと合成タッチの検査であり、実際に聴いたという意味ではありません。

## 実装・検証・素材

新規依存なし。音声ファイルなし。4個の固定音源、各ゲイン0.18・共通0.12、弦ごと90msの間隔。弦の視覚効果は4組まで。無操作1100msで音声処理停止。非表示・離脱・回転時の停止と遅い音声再開の破棄を検査します。

本企画用に生成した透過ギター画像を使用。配信WebPは472×960・55,906 bytes。原本と変換条件・ハッシュは `source-assets/poron-guitar/`。外部画像・音源の転載なし。背景・弦は軽量なDOM/CSSで描画。素材画像は弦の操作から分離しています。

`npm run check`、`npm test` の各段階を検査。入口件数が旧10件のままだった既存テストを11件へ更新後、風船以降のテストを順に再実行し、全段階がPASSしました（単一のnpm test実行が最後まで成功したという記録ではありません）。専用 `node tests/guitar.mjs` は6画面サイズ・56px対象・素材読込・タップ・速いなで・複数指・1万回の入力・固定音源／視覚効果上限・キー・キャンセル・非表示・resize・再入場・音声利用不可／再開遅延・reduced-motionを検査。既存テストの入口件数を11に更新し、ホームボタン・ブランド検査にも追加。

AWS公開設定は変更していません。未指定の遊びは本番ビルドから除外されます。
