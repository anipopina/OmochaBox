## 選定と内容

もぐもぐは動物へ食べ物を届ける遊び、シャボンは生成と破裂、風船は膨らませて飛ばす遊びです。本作は「粒がふくらんで別の形になる」「できたものを残し、もう一度触って跳ねる」を中心に選定しました。6粒は大きく固定し、読み書き不要。補充は粒と丸い矢印の絵ボタンで行い、勝手には消えません。子どもにとっての違いや理解しやすさは未検証です。

家の内部スクロール修正を踏まえ、ルートと画面はoverflow:clip。絵だけが動き、操作領域は固定。非表示・離脱時には音・アニメーションを止め、粒の状態を保持。点数・時間制限・調理器具や火の操作・空腹表現はありません。

## 確認方法

ZIPを展開し、`python3 -m http.server 4173 --directory dist` を起動して `http://127.0.0.1:4173/` から入ります。直接URLは `/pokopoko-popcorn/`。

1. それぞれの粒を触り、すぐにポップコーンに変わって跳ねること。
2. できたコーンをもう一度触り、消えずに反応すること。
3. 粒と丸い矢印の絵ボタンを押すと新しい6粒へ戻り、また遊べること。
4. 縦横表示・連打・複数指・別タブへの移動復帰・入口往復を確認。
5. 音色・音量と実機Safariを確認（制作者の環境では聴感と実機は未確認）。

## 確認範囲と限界

専用テストは6画面サイズ（320×568、390×844、820×1180、844×390、568×320、1280×900）、各1万回の入力、固定6粒、補充、音・アニメーション上限、キーボード、複数指・cancel、非表示・blur・pagehide・リサイズ時の保持、減らした動き、入口往復、画像decode失敗の再試行、音声API不能を検証。画像decode失敗はテスト注入であり、実回線障害の再現ではありません。モデルは10サイクル各1万入力を検証。

Web Audioは2つの固定正弦波、1音0.18秒、ゲイン合計最大0.014、発音間隔300ms。信号上の上限は聴感評価の代わりになりません。Chromiumのタッチ模擬は実機ではありません。実機Safari/iPhone/iPad、実際の音の聴感、幼児による理解しやすさは未確認です。

レビュー前のmainへのcommit/push、Sites更新、AWS変更、共有設定変更は行っていません。
