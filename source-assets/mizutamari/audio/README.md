# みずたまりの効果音

水面に触れたときの短い水音を、2026-11-26にStable Audio Open 1.0で3案生成しました。短い「ぽちょっ」、丸い「ぽちょん」、軽い「ぽちょっ」を比較できます。[生成条件、切り出し、音量、ハッシュの記録](review/round-1.json)

各候補から水音を1回分切り出し、低域と耳に刺さりやすい高域を抑え、前後をフェードしてモノラルのMP3に圧縮しました。生成原本のWAVは `tmp/audio-originals/mizutamari/generated/` に保管します。採用音は選定後に配信用として登録します。
