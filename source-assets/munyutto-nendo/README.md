# むにゅっとねんど 素材 2026-11-09

## 用途
- web/clay-material-reference.webp: 真上の平滑面・指くぼみ・太い溝を同じ光源で描いた素材参考。企画段階の見本であり、実装画面ではありません。画像自体を状態切替するのではなく、連続変形の材質・色・陰影の参考です。
- web/clay-ball.webp: まるめなおす操作と入口図案用のねんど玉。512×512、RGBA、約19KB。可視物体は中央約75%を占めます。
- source/: 選定した生成原本PNG。
- preview.png: 見本とねんど玉の大/160px表示の視覚確認用。
- validation.json: Web版寸法・容量・SHA256。

## 表現
鮮やかな暖色オレンジ、マットな高密度ねんど。上左から柔らかい光。くぼみの内側は暗く、押し出された縁は明るく盛り上がる。残るへこみと溝の形を主役にし、円の模様やペイントに見えないようにする。ねんど玉に外側の光彩はありません。

## 生成と加工
OpenAI内蔵image_genで本プロジェクト用に新規制作。第三者ストックは不使用。独占性や法的権利は保証しません。原本は保存し、Pillowでリサイズ・WebP圧縮のみ実施。透明背景は生成alphaを保持。画像編集による切抜き・色調変更なし。

## 生成指示の要旨
見本: 真上の同一の鮮やかなオレンジねんどを3パネル。左は平滑、中央は深い丸い指くぼみ、右は曲がった太い溝。クリームの机、上左光源、厚みある質感、文字・顔・手なし。
ねんど玉: 真透明背景の丸めたマットオレンジねんど。丸く少し不均一、中心75〜78%の大きさ。小さいUIで読める輪郭。外側の影・光彩・顔・文字なし。
