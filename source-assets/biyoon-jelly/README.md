# びよーんゼリーの素材

親タスクのクルミが2026-11-04にOpenAIの画像生成で制作し、本タスクへ提供したイチゴゼリーです。

- [Drive原本](https://drive.google.com/file/d/1dqPcHgX-zejQEoD-3ssbuz0YMbitaLC4/view)
- `original.png` は受領した1536×1024の原本を変更せず保持します。
- 組込み画像は `src/biyoon-jelly/assets/jelly.webp`。透明度4/255を超える範囲に32pxの余白を加えて切り出し、長辺640pxに縮小、WebP quality 90 / method 6で保存しました。外周のほぼ透明な画素を除く余白整理で、顔・輪郭・色・透明度そのものの描き直しはしていません。
- 寸法・容量・SHA-256・切り出し座標は `provenance.json` に記録します。
- 第三者のストック画像、外部フォントやアイコンCDNは使用していません。生成素材について排他的な権利や第三者ライセンスを推定しません。共有ホームアイコンの既存ライセンス表示は保持します。
- 皿と食卓背景はCSSで表現。操作対象のゼリー本体には生成画像を使用します。
