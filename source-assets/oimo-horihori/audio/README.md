# おいもほりほりの効果音

[採用記録](adopted.json)に選定結果と配信用MP3の対応を記録しています。露出完了にはカゴのA案を流用し、比較画面の露出完了欄ではC案として登録しました。カゴへの着地にはB案を使います。

[初回候補の制作記録](review/round-1.json)に、掘削、露出完了、持ち上げ、カゴへの着地の各2案について、原本WAV、生成・加工条件、試聴用MP3のハッシュを記録しています。

生成には [Stable Audio Open 1.0](https://huggingface.co/stabilityai/stable-audio-open-1.0) を使用しました。同じリビジョンの [ライセンス原文と利用条件の記録](../../ouchi-barabara/audio/README.md#利用条件) に従い、非商用の試作として生成音を加工・同梱し、採用後はWeb配信に使用できます。音源固有の帰属表示義務は確認されていません。商用目的でモデルを使う場合は登録と収益条件を確認します。
