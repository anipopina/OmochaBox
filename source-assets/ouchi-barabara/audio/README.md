# おうちバラバラの効果音

2026-11-11に、本プロジェクト用にStable Audio Open 1.0で生成しました。外部の録音素材・BGM・声のサンプルは取り込んでいません。生成条件・モデルのリビジョン・ツールの版は [generation.json](generation.json) に保持します。生成物の排他的な権利や第三者権利の不存在を保証するものではありません。

## 原本とリポジトリ容量

生成原本WAVはGit管理外の `tmp/audio-originals/ouchi-barabara/` に保存します。生成記録の `originals_directory` と加工記録の `source` はプロジェクトルートからの相対パスです。原本を移動してもSHA-256を保持し、音源IDと比較用MP3は変更しません。リポジトリには比較・配信用MP3、生成・加工条件、ハッシュ、利用条件と選定記録を残します。

比較画面とWeb配信はMP3を使い、WAVを取得しません。原本がない環境でもアプリのビルドと選定は可能です。再加工時は必要な原本を同じ配置へ復元してください。`tmp/` はGitに保存されないため、原本を長期保存する場合は別途バックアップが必要です。seedだけで同一波形の再生成は保証しません。

## 用途と加工

聴き比べ用の追加候補と記録は [review/](review/README.md) に分けています。候補の追加だけでは以下の採用音を変更しません。

| 素材 | 用途・生成時に指定した音 |
| --- | --- |
| hit | 家にバケットが当たる瞬間。木のおもちゃを叩く丸い打撃と小さな木の接触音 |
| collapse | 最後の打撃。積み木の家が崩れ、部品が次々に落ち着く音 |
| rubble | 全壊後に瓦礫や地面をつつく瞬間。小さな木片を軽く叩いて転がす音 |
| drive | 次の家へ走る間。小さな電動玩具のモーターとキャタピラの音 |

全候補で声・音楽を不要と指定しました。モデルの指定だけで不要音がないことを保証するものではありません。初回制作時には聴感・実機とも未確認でした。その後の選定内容は [提出された選定結果](review/selections/2026-11-11-v1.json) を参照してください。実機での確認は記録されていません。

2026-11-11の選定で打撃Aを維持し、走行は初回候補Cを採用しました。走行の原本・加工条件は `review/`、現在の配信ファイルとの対応は [optimization.json](optimization.json) に保持します。[adopted.json](adopted.json) により、通常の再加工でも選定済み音を未選定の原本へ戻さないようにしています。最後の打撃は、崩壊音だけに置き換えず、打撃音と同時に再生します。その後の選定で瓦礫Eを採用しました。途中の提出内容は [固定記号での選定結果](review/selections/2026-11-11-fixed-v1-selection-2.json) に保存しています。[最終選定](review/selections/2026-11-11-final.json) で最後の崩壊Mを採用し、途中の崩壊は不採用としました。現在の配信用音声はA・M・E・Cの4種類です。

原本は未加工の浮動小数点WAVです。振幅がPCMのフルスケールを超えるため、そのまま整数PCMへ変換・配信せず、[prepare.py](prepare.py) で加工します。不要な尾部の除去、モノラル化、低域・高域のフィルター、滑らかなピーク圧縮、前後のフェード、RMSとピーク双方によるレベル調整を行い、32kHz・64kbpsのMP3へ圧縮します。音源別の加工値はスクリプト、ファイル対応・容量・SHA-256・デコード後の測定値は [optimization.json](optimization.json) を正本とします。配信用は `src/ouchi-barabara/assets/` のMP3のみです。

再加工にはNumPy・SciPy・FFmpeg（libmp3lame対応）が必要です。`python prepare.py --ffmpeg <FFmpeg実行ファイル>` で実行できます。生成・加工ツールはアプリの実行時依存に含めません。
