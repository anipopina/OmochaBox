# Cの木製版とDの重量感の調整

2026-11-11の [選定メモ](../selections/2026-11-11-fixed-v1-selection-3.json) に基づく追加候補です。比較元は固定記号の最後の崩壊C（プラスチック版）と、途中の崩壊Dです。Aを参照した候補ではありません。既存音源と記号は変更しません。

- 最後の崩壊K・L・M：木製ブロックとして各2秒で生成。K・MはCの音声を初期音声としてStable Audioへ渡し、Lは初回Cのプロンプト構成とseedを使って材質を木に変更しました。音声参照を使っても、同じ崩れ方の再現を保証するものではありません。
- 途中の崩壊F・G：Dの接触の並びを保ち、再生速度と低域を少し調整した各1.5秒の加工候補です。大きな音にするだけの調整を避け、音量とピークを整えます。
- 途中の崩壊H：Dの音声を初期音声として、少し重い木片のコンセプトで再生成した1.5秒の候補です。

生成原本は生成記録の `originals_directory` に示すGit管理外の保管先、生成条件・参照音のSHA-256・モデルとツールの版は [generation.json](generation.json) に記録します。参照MP3は44.1kHzステレオの浮動小数点波形へデコードして `initial_audio_waveforms` として渡しました。生成時のサンプルレートはモデルの値に合わせます。加工と配信用変換は [prepare.py](prepare.py)、元音・出力のハッシュと測定値は [optimization.json](optimization.json) を正本とします。

モデル・音源の利用条件は [共通の素材記録](../../README.md#利用条件) と同じです。新しい外部録音素材は追加していません。音色・木らしさ・重量感・操作との相性の採用判断は人が聴いて行います。生成・加工しただけでは通常の遊びへ採用しません。
