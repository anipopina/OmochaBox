# 軽い積み木の崩れ・新規生成

2026-11-11に、既存の崩壊音Aやその加工音を参照せず、Stable Audio Open 1.0から新しく生成しました。「軽めの積み木が一度に崩れる」「細かい不規則な衝突が重なり、静まる」音を指定し、規則的なノック・反復打撃・足音・音楽・声などを除外指示に入れています。Aの後半に残っていた反復音を加工で薄める方針は採っていません。

- `collapse-h`・`collapse-i`・`collapse-j`：最後の崩壊用、各2秒。
- `crumble-c`・`crumble-d`・`crumble-e`：途中の崩壊用、各1.5秒。

生成原本は生成記録の `originals_directory` に示すGit管理外の保管先、モデルの版・プロンプト・除外指示・seed・ツールの版は [generation.json](generation.json) に保持します。既存音声の参照・切り貼り・時間伸縮はありません。加工は [prepare.py](prepare.py) による帯域・音量調整とファイル端の短いフェード、モノラル化・MP3圧縮です。対応ファイル・ハッシュ・容量・測定値は [optimization.json](optimization.json) を参照してください。素材の利用条件は [音源共通の記録](../../README.md#利用条件) と同じで、新しい外部録音素材は含めません。

音量包絡と目立つピークの間隔を機械的に記録していますが、規則的な打撃音が聞こえないことや聴感上の品質を保証する検査ではありません。実際の音色・不要な反復音・減衰の自然さは人が聴き比べて判断します。生成しただけでは通常の遊びへ採用しません。既存のA〜Gおよび途中崩壊A・Bは別音源として保持し、記号を付け替えません。

再選定中の古い音が新候補の試聴へ混ざらないよう、プレビューでは「作り直す」の場面を無音にします。通常の遊びの採用音は選定前に自動変更しません。
