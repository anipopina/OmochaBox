# ぷかぷか、ふうせんの効果音

ポンプの空気音、風船の放出とタップ、最大サイズの合図向けに Stable Audio Open 1.0 で生成した候補です。原本WAVは `tmp/audio-originals/pukapuka-fusen/generated/` に保管します。生成条件、切り出し範囲、加工後の測定値とハッシュは [初回の制作記録](review/round-1.json) と [追加候補の制作記録](review/round-2.json) を参照してください。

追加候補では、空気音を最大サイズまでの時間に揃えました。放す音は最大サイズのB案から響きを変えて2種類、弾く音は弾きBの成分を重ねた3種類を用意しました。最大サイズの合図は、軽い光を想起させる音に作り直しています。[聴き比べ後の選定結果](review/selections/2026-11-26-first-feedback.json)

最終選定で、ポンプはD、放す音はC・D、弾く音はC・D・Eを採用しました。最大サイズの場面は、選定メモが指定したポンプAのMP3をそのまま使います。比較画面にも同じ音を最大サイズのEとして登録しています。[最終選定](review/selections/2026-11-26-final.json)・[採用候補と配信ファイルの対応](adopted.json)

モデルとリビジョンは [公式モデルページ](https://huggingface.co/stabilityai/stable-audio-open-1.0) と [モデル規約の保存原文](../../ouchi-barabara/audio/MODEL-LICENSE.md) を確認しました。2026-11-26時点で、同じリビジョンに対する [既存の利用条件の記録](../../ouchi-barabara/audio/README.md#利用条件) を適用しています。生成音は非商用の試作・評価として加工し、聴き比べ用MP3をリポジトリに同梱します。規約の出力の扱いに基づき音源のみのWeb配信に使用でき、音源固有の帰属表示は求められていません。商用目的での制作に変わる場合は登録と収益条件を確認します。
