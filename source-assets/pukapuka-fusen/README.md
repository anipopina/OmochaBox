## 2026-10-29 見た目の修正（独立レビュー待ち）

対象はクルミ看板「ふうせん: 見た目の修正」（https://app.notion.com/p/40899535a51a805493d6d3f68eae3d34）の選択済み3項目。

- 本体の線は中央描画に統一。512幅の座標系では14、370幅のcyanでは10.1171875とし、同じ画像表示幅で同じ見かけの太さにする。cyanの結び目・ひもの線も同じ比率へ揃えた。
- starの結び目の上端を448から402へ移動し、本体の中央の谷（y=408）に重ねた。ひもは新しい結び目の下端から既存の末端へつなぎ直した。

- 新しい画像生成や第三者素材、依存関係の追加はない。既存の素材系列を維持する変更。
