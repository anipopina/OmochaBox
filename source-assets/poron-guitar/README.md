# ぽろんギターの素材

2026-10-30、本企画用にOpenAI image_genで生成。外部ストック画像の転載・第三者ライセンス素材は使用していません。排他的権利の保証は推定しません。

参照企画: https://drive.google.com/file/d/1wbo-tsw3UAUMhd5js01xDBQXoStcx89o/view 。初期候補の「太い弦のタップ／なで操作、音が合う、BGMなし」を採用。生成時は幼児向けの鮮やかな黄金色の木製ギター、赤いヘッド、濃い輪郭、正面、文字・弦・手・顔なし、透明背景を指定。身体画像と弦の操作を分離しました。

原本: `generated-guitar.png`（1086×1448）。透過外周の微小アルファを除くためアルファ>10のbbox (198,28,886,1427) で余白をトリミング。Pillowで最大640×960に縮小し、quality=86 / method=6のWebPに変換。配信は472×960、55,906 bytes。原本は配信しません。SHA256とサイズは `provenance.json`。

音はWeb Audioで本実装が合成する4音の減衰音。録音・サンプル音源・BGM・外部音源ライセンスへの依存はありません。共通ホームアイコンの既存ライセンスは src/shared/icons を維持。
