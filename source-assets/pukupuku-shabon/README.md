# ぷくぷくシャボンの入口カード

[撮影原本PNG](card-original.png) は、遊びの[青空・雲・泡・破裂の光粒のスタイル](../../src/pukupuku-shabon/style.css)を使って場面を組み直し、Chromiumで撮影したものです。狭いカードでも中身が伝わるように、泡に入った「コーラルのしかく」と、割れた泡から出た「きいろいさんかく」を中央に寄せています。割れた泡は、飛び散る光粒で表現しています。

キャラクターの出典と利用に関する記録は [共通キャラクター素材](../characters/README.md) を参照してください。既存のプロジェクト素材からカードを制作しています。

[配信用WebP](../../src/assets/previews/pukupuku-shabon.webp) は原本と同じ場面をChromiumでWebP品質86として書き出したものです。解像度は1200×600、容量は33,490バイトです。
