# ぴたっとマグネット 素材

磁石は2026-11-05に本プロジェクト用にOpenAI画像生成で制作。
原本: https://drive.google.com/file/d/16-2cCaWqEEtRw07jPGhF6ZRxfx_oMhwz/view
`magnet-original.png` は取得した原本。透過・輪郭を目視確認し、α>12の境界で余白を除き、長辺420px、quality86のWebPとして組込みました。外部ストック素材は使用していません。権利の排他性や第三者ライセンスは推定していません。

玩具も同日に本プロジェクト用にOpenAI画像生成したものです。αを維持し、透明余白をトリム、長辺240px、quality86のWebPに変換。原本は変更せず保持。画像を目視し、背景への合成でも透過を確認しています。各変換値・サイズ・SHA-256は optimization.json に記録。
