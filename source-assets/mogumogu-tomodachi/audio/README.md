# もぐもぐともだちの効果音

[採用記録](adopted.json)に選定結果と配信用MP3の対応を記録しています。もぐもぐはA案、ごっくんはC案を、試聴用MP3から再圧縮せず配信します。交代は無音です。

[初回](review/round-1.json)と[追加候補](review/round-2.json)の制作記録に、原本WAV、生成・加工条件、試聴用MP3のハッシュを記録しています。追加のもぐもぐ音は硬い野菜とやわらかい果肉の咀嚼を想定し、それぞれ異なる3つの音を切り出して並べています。追加のごっくん音は飲み込む音の低い成分を残し、余韻の長さと乾いた質感に違いを持たせています。候補と採用状態は[効果音の台帳](../../../src/mogumogu-tomodachi/sound-review/review.json)で管理します。

2026-11-27に、[Stable Audio Open 1.0の公式モデル情報](https://huggingface.co/stabilityai/stable-audio-open-1.0)と、同じリビジョンの[ライセンス原文と利用条件の記録](../../ouchi-barabara/audio/README.md#利用条件)を確認しました。Stability AI Community License Agreementの生成出力に関する条項に従い、非商用の試作として加工した生成音のみを同梱し、採用後はWeb配信できます。音源固有の帰属表示義務は確認されていません。商用目的でモデルを使う場合は登録と収益条件を確認します。
