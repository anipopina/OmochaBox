水族館の原本は [Google Drive](https://drive.google.com/file/d/1FShFZtaLVgRzV7Lgh5uve7keaJU7g9qM/view) にあります。AI制作の元v1ではなくユーザー手動修正版です。ペンギン、クマノミ、エイ、クラゲ、タコ、カニ、イルカ、ヒトデの8点で、元のファイル名を保持しています。ZIPのSHA-256は `dc2a4ef23db0646b5d83ab2f559ceeb5542ed8aa62752318eec91b8fbb9e5232`。

[sha256.json](sha256.json) はコピー元と照合済みの各SVGのSHA-256です。`node tests/characters.mjs` で全14点の存在・内容一致・シリーズ構成を確認できます。

水族館の01〜07にはInkscapeバージョン、編集画面の位置・寸法・ズーム、レイヤー選択、SVGファイル名などの編集設定が含まれます。秘密情報、ローカルファイルパス、外部画像参照、スクリプトは検出されませんでした。編集設定も原本の一部として保持しています。

素材の追加だけではゲームのパレットや一覧へ登録されません。採用する素材や画風は各おもちゃで個別に決め、キャラクター利用を必須にしません。
