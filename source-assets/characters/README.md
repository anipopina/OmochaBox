# シリーズ別キャラクターSVG

配信用・再利用用SVGは [src/assets/characters/](../../src/assets/characters/) でシリーズ別に管理します。すべてユーザー提供の原本をバイト単位で保持し、再描画・最適化・整形は行っていません。作者やライセンスは推定しません。

| シリーズ | 保存先 | 原本・出典 |
| --- | --- | --- |
| 図形のなかま 6点 | `shapes/` | main `14170a9` の `src/assets/characters/` から内容変更なしで移動 |
| 水族館のペンギン3点 | `aquarium/01-penguin-{a,b,e}.svg` | ユーザー提供の `penguin-{a,b,e}-2.svg`。内容を変更せず配信用に改名 |
| 水族館のほかの7点 | `aquarium/02-`〜`08-` | ユーザーの「水族館シリーズ_SVG8点_v1_手動修正版.zip」（14,817 bytes）からそのままコピー |

初期の水族館8点の原本は [Google Drive](https://drive.google.com/file/d/1FShFZtaLVgRzV7Lgh5uve7keaJU7g9qM/view) にあります。AI制作の元v1ではなくユーザー手動修正版です。ペンギン、クマノミ、エイ、クラゲ、タコ、カニ、イルカ、ヒトデの8点でした。ペンギン以外の7点は元のファイル名を保持しています。ZIPのSHA-256は `dc2a4ef23db0646b5d83ab2f559ceeb5542ed8aa62752318eec91b8fbb9e5232`。

2026-11-10にペンギンを更新しました。`penguin-b-2.svg` で既存ペンギンを差し替え、A・Eを追加しています。配信用ファイル名の `01-` はペンギンのグループ番号とし、版を示す `-2` は外しています。元の縦横比・透過・メタデータは保持しています。SVG内の参照は内部グラデーションのみで、外部画像・スクリプト・ローカルパスはありません。

新しい3点は、このリポジトリへの取り込みとスタンプでの利用を目的としてユーザーから提供されました。作者・第三者ライセンス・別用途への再配布条件は資料に記載されていないため推定しません。既存メタデータを保持し、一般向けの素材ライセンスは付与しません。

[sha256.json](sha256.json) はコピー元と照合済みの各SVGのSHA-256です。`node tests/characters.mjs` で全16点の存在・内容一致・シリーズ構成を確認できます。

初期の水族館01〜07にはInkscapeバージョン、編集画面の位置・寸法・ズーム、レイヤー選択、SVGファイル名などの編集設定が含まれます。秘密情報、ローカルファイルパス、外部画像参照、スクリプトは検出されませんでした。編集設定も原本の一部として保持しています。

素材の追加だけではゲームのパレットや一覧へ登録されません。採用する素材や画風は各おもちゃで個別に決め、キャラクター利用を必須にしません。
