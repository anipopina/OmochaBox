# ひかりのおえかき

幼児向けの小さなCanvasのおもちゃ。濃紺の庭をなぞると、明瞭な太い線と星・丸の粒が現れ、指を離すとふっくら丸い6枚の花びらと花芯を持つ花が咲きます。短いタップでも開花します。右上に「音あり／消音」の切り替えがあります。

## 6秒で育つ光（v5）

- 指を止めていても、その周囲から星・丸の粒が出続け、光の輪が育ちます。各指の開始時刻から `min(経過ms / 6000, 1)` で成長するため、3秒では成長の半分、6秒で正確に最大です。6秒以降は一定。最大到達時には指ごとに1回だけ18粒のバーストと650msの局所的な輪・星が現れます。画面全体のフラッシュはありません。
- 初期花サイズと線幅はv3のままです。花のチャージ倍率は0秒1.0倍、3秒1.5倍、6秒2.0倍、9秒でも2.0倍。丸い花びら・花芯・四隅の葉素材も維持しています。
- CSS描画領域の短辺 / 390を0.85〜1.22に制限し、花・線・粒径・飛距離へ共通適用。DPRは描画解像度だけに使用。390px短辺で通常の花の半径約76px、最大約152px、線幅21px。大画面では花の半径は通常約93px、最大約186pxが上限です。端で咲く花は画面端で切れることがあります。
- 粒は0秒で160msごとに2個、6秒で80msごとに4個。通常粒の速度は最大3倍、大きさは最大2.2倍。フレーム遅延時のまとめ出しはせず、バーストも含め全粒220個の上限を維持します。
- 継続タッチ中のきらめき音は、下記の提供MP3に置き換えました。花が咲く短いサイン波の音は維持しています。
- ミュート・非表示は即座に発音ノードを停止。離す／キャンセル後は新しいきらめき音を発生させません。発音の予約キューを作らず、ミュート解除や復帰で過去音をまとめて再生しません。
- 全指が離れ、既存効果が消えると描画停止。キャンセル・非表示時にはチャージを破棄し、後から開花しません。

## 四隅の背景（v4）

承認済みの透明PNG4枚を指定された四隅に1枚ずつ配置しました。鏡像による代替はなく、塗りの質感をそのまま使用しています。各画像は短辺の46%・最大330 CSS pxの同サイズ、明度を保つ不透明度83%。中央の放射状背景と組み合わせ、下端の草原と縦方向グラデーションを取り除きました。

葉は背景用Canvasに合成され、入力を受けるDOM要素は増やしていません。線・花・粒より背面にあり、葉の上も描画できます。画像読込時とリサイズ時だけ背景を作り直します。v5でもこの背景は変更していません。

原本は `source-assets/`、配信画像は `dist/assets/` に元の1254×1254 PNGのまま保持。4枚合計約4.8MBです。Library由来のID・版情報は `source-assets/library-provenance.json`、正式な拡張属性つき原本は取得時のWSL作業領域にも保持しています。

iPhone縦横・iPad縦横・デスクトップの5サイズを `test-results/garden-*.png` で目視確認。4画像のHTTP配信・読込、葉の上のタップ、回転相当リサイズ、6秒チャージ・複数指・音・ミュート・終了後停止の回帰検証を実施しました。

## 提供MP3のきらめき音

`dist/assets/ta_ta_hosikuzu01.mp3` はユーザー提供の原本47953 bytesです。Library ID・版情報は `source-assets/audio-provenance.json` に記録し、WSL上の原本にも正式な拡張属性を保持しています。

- ffprobeでMP3 / 44100Hz / モノラルを確認。ヘッダー推定7.3095秒、実デコード7.28816秒。ffmpegの実サンプル解析ではピーク-22.2dBFS、全体RMS相当-37.2dB。0〜0.5秒のRMS -42dB、1〜3秒は約-35〜-34dB、その後減衰し6.5〜7秒は約-53dB、最後は約-69dBでした。
- 実際の音色を聴いた評価はしていません。上記は形式・サンプル・音量包絡の機械解析です。
- 最初の音を使う操作でAudioContextを有効化し、同じSiteから1回取得して `decodeAudioData`。共有AudioBufferを全指で使い回します。読込中・失敗時も描画を続け、素材の代わりに合成きらめきを重ねません。
- 現在触れている指の最大チャージを共通音量に反映し、4.8秒間隔で全指合計1回ずつ再生。MP3音源は最大2個（自然な余韻が約2.5秒重なる）、花の音を含む全音源は最大4個。毎フレームの再生・音の予約キュー・無制限な多指合算はありません。
- MP3 gainは0秒0.75、3秒1.5、6秒以降2.25。初期から最大まで約9.5dBの制御差。開始40msのattackと120ms程度の音量追従で、素材そのものの早い立ち上がりと長い余韻を保ちます。MP3 2個合計gainは最大4.5、master gain 0.22、DynamicsCompressor（threshold -24dB / ratio 8）を維持します。
- 最後の指を離すと新規再生を止め、残りを最大1.2秒でなだらかに消音。最後の指のcancelは80msで消音。ミュート・非表示は即時停止。再開は現在の操作だけから発音し、ロード完了時に離した過去のタッチを遅れて再生しません。
- 花の開花音は従来どおりgain 0.24、約360ms、全花で150ms以上の発音間隔です。

Chromeの実AudioBufferSourceで素材バッファ使用と約7.3秒のデコードを確認。HTTPの `audio/mpeg`、配信バイト一致、単一取得、初回ロード中に離した後の無再生、保持・6秒最大・多指上限・ミュート・キャンセル・非表示復帰・余韻上限を検証。HTTP503の故障注入でも例外なく開花を確認しました。実機iOSおよび音色・音量の聴感は未検証です。

## 起動

インストール・ビルド不要。`dist/index.html` を開くか、`python -m http.server 8000 --directory dist` を実行して `http://localhost:8000` を開きます。ソースは `dist/index.html`、`dist/style.css`、`dist/app.js` です。

## 体験と上限

- 描画順は背景→線→花→指先・粒。線同士と花同士は配列の安定した生成順で古いものから描き、新しいものが手前になります。同じ時刻・複数指でも挿入順を維持。古い花も新しい線より前です。`test-results/layer-order.png` と重なりのRGBピクセル検査で確認しています。

- pointerdownは輪と粒から始まります。正常なpointerupの終点で1回だけ開花し、短い柔らかな音が鳴ります。キャンセル・キャプチャ喪失・画面離脱後の遅れたupでは開花しません。
- ドラッグ中は指の後ろから元気な粒。線は約2.7秒後、古い短区間から浮かぶ粒へ変わります。
- 花は約3.65秒まで形を保ち、花びらが順に先端から縮んで粒を放ちます。最後に花芯が小さな星になり、約5.1秒で本体が消えます。消滅粒は最大1.5秒で消え、末尾220msだけフェードします。
- 最大10指、線480区間、花24個、粒220個、音4声（MP3はそのうち最大2声）。上限時は古い視覚効果を置換し、処理や音の予約を積みません。音声ノードは終了時に切断します。
- 下端・左右の庭はリサイズ時だけ別Canvasに描画。全効果がなくなるとrequestAnimationFrameが停止します。描画解像度はDPR 2かつ約400万画素までです。
- 最初の操作でWeb Audioを有効化。利用できなくても絵で遊べます。設定・絵の保存、解析、広告、外部ライブラリはありません。背景画像とMP3は同じSiteから読み込みます。
- リサイズ・回転・blur・pagehide・visibilitychange時には入力と効果を整理。バックグラウンドでは音も停止し、復帰後の操作で再開します。
- touch-action:noneでアプリ内スクロールを抑止します。OSの端ジェスチャーやブラウザ固有操作の完全抑止は想定していません。
- 48px以上のミュート操作はキーボードでも利用可能。自由描画はタッチ／マウス用です。動きを減らす設定では開花の拡大を省き、粒の移動を抑えます。

## 検証

Node.js 24とChromeがあれば `node tests/browser.mjs` で再現できます。標準Windowsパス以外のChromeは `CHROME_PATH` で指定します。追加パッケージ不要。専用の一時ブラウザプロファイルとローカルサーバーを使い、終了時に片付けます。状態確認フックはテストサーバーが挿入し、本番ソースにはありません。

2026-10-04 Windows / ヘッドレスChrome:

- iPhone相当390×844、844×390、iPad相当820×1180、デスクトップ1280×800。表示・複数指・短いタップ・upで1回の開花・cancel後に開花しないことを確認。
- ブラウザのマウス入力で音の有効化・発音・ミュートを確認。
- 2,000回のタップ＋ドラッグ、5,000回の長いドラッグ移動で上限維持。
- 操作後6.9秒で全効果と音が消え、描画停止。線の粒への変化と花びらの順次消滅を状態と画像で確認。
- リサイズ・pagehide/pageshow相当のイベントと復帰後の再操作。ブラウザJavaScript例外なし。
- 0/3/5.999/6/9秒でチャージと花径を確認。初期径不変、倍率1/1.5/2/2、実時間の静止6秒、独立した2指、各指1回のバーストと継続きらめき音を確認。
- 10指長押しで音・粒の上限、ピーク演出の非反復、花の音の150ms以上の間隔、MP3の2音源上限と共有バッファ、gain上限、ミュート・キャンセル・非表示相当イベントからの復帰で遅延音がないことを確認。
- 4サイズで最大花2個と通常花を並べた比較画像を生成し、サイズ上限と重なりを視覚確認。

`test-results/results.txt` に検証結果、同フォルダに4サイズの画像・`*-charge-comparison.png`（最大花2個と通常花）・`stationary-6s-and-3s.png`（静止6秒と3秒の2指）・`v2-iphone-portrait.png`（前版）・`dissolving.png`（消滅途中）があります。画像を実際に表示して視覚確認しました。

**実機iPhone/iPad Safari、実際の複数指、実際のバックグラウンド復帰、OS端ジェスチャー、音色の聴感は未検証です。** 画面サイズのエミュレーションは実機検証の代用ではありません。

## 配信

既存のSite IDとURLを維持し、所有者のみの非公開アクセスで配信します。Sites側の閲覧認証が必要な場合がありますが、おもちゃ自体にログイン機能はありません。
