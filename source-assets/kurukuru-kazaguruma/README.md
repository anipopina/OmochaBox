## 制作と確認

遊びのTypeScript・CSS・HTMLと組込みSVGは、親が共有した企画と画像を基にCodexが本プロジェクト向けに制作しました。SVGは企画PNGの切り抜きや埋込みではなく、曲線の輪郭・折れ面・留め具をベクターで描き直したものです。第三者素材の転載や外部フォント・アイコンの取得は行っていません。企画画像について元資料にない権利保証は推定しません。

2026-10-24に親が既存Sites v18をクラウドブラウザーでレビューし、タップ、上側を左へ払う逆回転、矢印キー、入口往復・再入場、新カード、回転時のヘッダーとの間隔を確認しました。スマホ縦・小画面横の画像も確認済みです。実機Safariは未確認です。
