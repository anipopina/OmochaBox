# つみつみアイスの素材

2026-11-03にこの企画用にOpenAI ImageGenで制作したコーン・いちご・バニラ・チョコの4素材を使用します。生成原本は `generated-sheet.png`。各627×627の区画を切り出し、透明な外縁をトリミングして320×320以内へ縮小し、ImageMagickで透過WebP（品質85）へ変換しました。配信用の4点は合計約81KBです。第三者のストック素材や外部配信への依存はありません。排他的な権利保証は推定しません。

いちごの粒、バニラの星、チョコのかけらを使い、色だけでなく絵柄でも選べるようにします。配信用画像は透過WebPとし、元画像は変更せず保存します。
